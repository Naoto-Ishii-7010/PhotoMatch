## 1. サービス概要

### サービス名

**PhotoMatch**

### 一言説明

写真撮影を依頼したいユーザー（ゲスト）と、趣味でカメラを楽しむアマチュアフォトグラファー（ホスト）をつなぐ、C2C 写真撮影マッチングサービス。

### 背景

- プロスタジオへの依頼は ¥30,000〜 と高額で、気軽に使えない
- スマホ写真では品質が物足りないが、プロに頼むほどでもないシーンが多数ある
- 趣味でカメラを持つアマチュアは多く、技術を活かす場がない

### 解決したい課題

- 課題1: 「プロに頼むほどじゃないけど、ちゃんとした写真が欲しい」というニーズに応える場がない
- 課題2: アマチュアフォトグラファーが自分のペースで副収入を得る手段がない
- 課題3: 知らない人に撮影を依頼する際の安心・安全の仕組みが整っていない

---

## 2. ターゲットユーザー

**対象国**: 日本のみ / **言語**: 日本語のみ

### 主なユーザー

- **ゲスト（依頼者）**: 家族写真・記念日・プロフィール・ペット・七五三・スポーツシーンなど、思い出をちゃんと残したい日本在住のユーザー
- **ホスト（フォトグラファー）**: カメラが趣味で、週末や空き時間を使って副収入を得たい日本在住のアマチュアフォトグラファー

## 4. ユーザー体験の全体像

### 基本フロー

1. ゲストが無料登録（Google アカウント、30秒）
2. ゲストが撮影希望（シーン・場所・予算）を投稿、または特定ホストを指名
3. ホストがチャットで価格・内容・納品形式を提案
4. 双方合意 → 依頼確定・エスクロー決済（仮押さえ）
5. 撮影当日：合意した場所・時間で撮影
6. ホストが写真を納品アップロード
7. ゲストが納品写真を確認・承認 → 決済確定、売上がホストへ

### 主要ユースケース

- **ゲスト / 指名型**: ポートフォリオを見て気に入ったホストへ直接依頼する
- **ゲスト / 公募型**: 「¥5,000・公園・カップルフォト」と投稿し、複数の提案から選ぶ
- **ホスト / 応募**: 公開された公募依頼を見つけて提案を送る
- **ホスト / 指名受付**: ゲストからの指名依頼を確認・承認する

## 6. ビジネスルール

- 1ユーザーがゲスト・ホスト **両方の役割** を持てる（同一アカウントで切り替えて利用）
- 価格は **相談制**：ゲストが予算を提示し、ホストが条件を提案、双方合意で成立
- 撮影場所は **ゲストが指定**し、ホストが赴く（交通費の扱いは事前チャットで合意）
- 決済は **エスクロー方式**：仮押さえ後、ゲストの納品承認をもって売上確定
- キャンセルは撮影日の一定期間前まで無料。以降はキャンセルポリシーに従う
- 納品に満足できない場合、運営が仲介し返金対応する
- プラットフォーム手数料（率は未定）をゲスト支払い額から控除してホストへ振り込む
