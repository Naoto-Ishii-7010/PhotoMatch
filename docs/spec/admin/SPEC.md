# 機能仕様：運営管理

## 1. 機能概要

### 機能名

運営管理

### 機能の目的

運営スタッフがユーザー管理・通報対応などのプラットフォーム運営業務を行えるようにする。

### この機能で解決する課題

- 不正ユーザー・トラブルへの迅速対応でプラットフォームの安全性を維持する

---

## 2. 対象ユーザー

### 主な利用者

- 運営スタッフ・管理者

### 利用シーン

- ユーザーから通報が届いたとき
- 不正・規約違反のユーザーを停止・退会させるとき

---

## 3. 機能スコープ

### この機能に含むもの

- ユーザー一覧の閲覧・検索
- ユーザーの詳細情報確認（プロフィール・依頼履歴・通報履歴）
- ユーザーの停止・退会処理
- 通報一覧の確認・対応

### この機能に含まないもの

- 一般ユーザーによるアクセス（管理者のみ）
- 自動モデレーション（MVP対象外）

---

## 4. ユーザーアクション

### ユーザーができること（管理者）

- ユーザーを検索・一覧表示する
- ユーザーの詳細情報・依頼履歴を確認する
- ユーザーを停止・退会処理する
- 通報を確認し、対応済みに更新する

### ユーザーができないこと

- 一般ユーザーが管理画面にアクセスする

---

## 5. 正常系フロー

### ユーザー停止

1. 管理者がユーザー一覧から対象ユーザーを検索する
2. ユーザーの詳細情報・通報履歴を確認する
3. 「アカウント停止」ボタンをタップし、理由を入力する
4. 対象ユーザーのアカウントが停止され、ログイン不可となる
5. 対象ユーザーへ停止通知が送信される

### 通報対応

1. 管理者が通報一覧を確認する
2. 通報の内容（通報者・対象ユーザー・理由・日時）を確認する
3. 対応を決定する（警告・停止・問題なしなど）
4. 対応内容を入力し、対応済みに更新する

---

## 6. 例外・エラーケース

| ケース                                 | 表示・挙動                             |
| -------------------------------------- | -------------------------------------- |
| 停止済みユーザーを再度停止しようとした | 「すでに停止済みのユーザーです」と表示 |

---

## 7. ビジネスルール

- 管理画面へのアクセスは管理者ロールのユーザーのみ可能
- ユーザー停止はアカウントを無効化し、ログイン・サービス利用を不可にする

---

## 8. 関連仕様

- 通知（停止通知の送信）
