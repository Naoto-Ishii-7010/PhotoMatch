# 機能仕様：新規登録・ログイン

## 1. 機能概要

### 機能名

新規登録・ログイン

### 機能の目的

Googleアカウントを利用して、ユーザーがPhotoMatchに登録・ログインできるようにする。

### この機能で解決する課題

- メールアドレス・パスワード管理の煩雑さをなくし、30秒以内に登録を完了できる
- 1つのアカウントで依頼者・フォトグラファーの両方の役割を利用できる

---

## 2. 対象ユーザー

### 主な利用者

- PhotoMatchを初めて利用するすべてのユーザー
- ログアウト後に再度サービスを利用するユーザー

### 利用シーン

- 撮影を依頼したい、または受けたいと思いサービスに登録するとき
- ログアウト後に再ログインするとき

---

## 3. 機能スコープ

### この機能に含むもの

- Googleアカウントによる新規登録
- Googleアカウントによるログイン
- セッション管理（ログイン状態の維持）
- ログアウト

### この機能に含まないもの

- メールアドレス・パスワードによる認証
- Google以外のOAuth連携
- プロフィール情報の設定（プロフィール管理で対応）
- 退会機能

---

## 4. ユーザーアクション

### ユーザーができること

- Googleアカウントで新規登録する
- Googleアカウントでログインする
- ログアウトする

### ユーザーができないこと

- メールアドレス・パスワードでの登録・ログイン
- Google以外のアカウントでの登録・ログイン

---

## 5. 正常系フロー

### 新規登録

1. ユーザーが登録画面の「Googleで登録する」ボタンをタップ
2. Google認証画面に遷移し、使用するアカウントを選択・許可
3. 認証成功後、新規ユーザーデータを作成
4. プロフィール設定画面（プロフィール管理）へリダイレクト

### ログイン

1. ユーザーがログイン画面の「Googleでログインする」ボタンをタップ
2. Google認証画面に遷移し、使用するアカウントを選択・許可
3. 認証成功後、既存アカウントのセッションを開始
4. ログイン前にアクセスしていたページ、またはホーム画面へリダイレクト

### ログアウト

1. ユーザーがメニューから「ログアウト」を選択
2. セッションを破棄
3. トップページへリダイレクト

---

## 6. 例外・エラーケース

| ケース                                                 | 表示・挙動                                     |
| ------------------------------------------------------ | ---------------------------------------------- |
| Google認証画面でキャンセルした                         | 登録・ログイン画面に戻る                       |
| Google側でエラーが発生した                             | エラーメッセージを表示し、再試行を促す         |
| サーバーエラーが発生した                               | エラーメッセージを表示し、再試行を促す         |
| 既存アカウントと同じGoogleアカウントで登録しようとした | ログインとして処理し、ホーム画面へリダイレクト |

---

## 7. ビジネスルール

- 1ユーザーが依頼者・フォトグラファー両方の役割を同一アカウントで持てる
- GoogleアカウントのメールアドレスをユーザーIDとして使用する
- 既存アカウントと同一のGoogleアカウントで登録した場合、ログインとして扱う
- メールアドレスは他のユーザーに対して一切表示しない（内部管理用途のみ）
- サービス上の表示名はGoogleアカウントの表示名を初期値として使用する
- 表示名はプロフィール管理から変更できる
