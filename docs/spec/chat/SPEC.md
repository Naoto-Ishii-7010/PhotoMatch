# 機能仕様：チャット

## 1. 機能概要

### 機能名

チャット

### 機能の目的

依頼者とフォトグラファーがアプリ内でテキストチャットを通じてコミュニケーションできるようにする。

### この機能で解決する課題

- 知らない相手との撮影依頼において、事前のやり取りで安心感・信頼感を醸成できる
- 価格・撮影内容・場所などの詳細を依頼確定前に詰められる

---

## 2. 対象ユーザー

### 主な利用者

- 依頼者とフォトグラファー（依頼に紐づいた1対1のチャット）

### 利用シーン

- 指名型依頼・公募型依頼の前後に、撮影内容・条件・日程をすり合わせるとき
- 依頼確定後に撮影当日の詳細を確認するとき

---

## 3. 機能スコープ

### この機能に含むもの

- テキストメッセージの送受信
- 依頼に紐づいた1対1のチャットルーム
- メッセージの既読確認
- 過去メッセージの表示（スクロールで遡れる）

### この機能に含まないもの

- グループチャット
- 画像・ファイルの添付送信
- 納品写真の送付（納品で対応）

---

## 4. ユーザーアクション

### ユーザーができること

- メッセージを送信する
- 受信したメッセージを閲覧する
- 過去のメッセージ履歴をスクロールして確認する
- メッセージの既読状態を確認する

### ユーザーができないこと

- メッセージを削除・編集する
- 画像・ファイルを添付して送信する
- 相手をブロックする（運営への通報は運営管理で対応）

---

## 5. 正常系フロー

1. 依頼者またはフォトグラファーがチャット画面を開く
2. テキストを入力して「送信」ボタンをタップ
3. 相手にメッセージ通知が届く（通知）
4. 相手がチャット画面を開くとメッセージが既読になる

---

## 6. 例外・エラーケース

| ケース                                     | 表示・挙動                                           |
| ------------------------------------------ | ---------------------------------------------------- |
| メッセージが未入力の状態で送信しようとした | 送信ボタンを無効化する                               |
| メッセージが文字数上限を超えた             | 入力中にリアルタイムで文字数を表示し、上限超過を通知 |
| ネットワークエラーで送信に失敗した         | 「送信に失敗しました」と表示し、再送信を促す         |

---

## 7. ビジネスルール

- チャットは依頼に紐づく1対1のみ。任意の相手とのチャットは開始できない
- 依頼に関係する依頼者・フォトグラファーのみアクセス可能
- メッセージの削除・編集は不可

---

## 8. 関連仕様

- 指名型依頼（依頼に紐づいてチャットルームが生成される）
- 公募型依頼・提案比較・選択（依頼確定後にチャットルームが生成される）
- 通知（新規メッセージの通知）
- 運営管理（不適切なメッセージの通報対応）
