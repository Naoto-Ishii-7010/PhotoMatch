# 機能仕様：納品・納品確認

## 1. 機能概要

### 機能名

納品・納品確認

### 機能の目的

フォトグラファーが撮影写真をアップロードして依頼者に納品し、依頼者が写真を確認・承認・ダウンロードできるようにする。

### この機能で解決する課題

- 撮影後の写真受け渡しをアプリ内で完結させ、安全・確実に納品できる
- 依頼者による承認をトリガーに決済を確定させることで、納品品質を担保する

---

## 2. 対象ユーザー

### 主な利用者

- フォトグラファー（撮影写真をアップロードする側）
- 依頼者（写真を確認・承認・ダウンロードする側）

### 利用シーン

- フォトグラファーが撮影後に写真を編集・セレクトして納品するとき
- 依頼者が納品写真を確認し、承認またはやり直しを求めるとき

---

## 3. 機能スコープ

### この機能に含むもの

- フォトグラファーによる写真のアップロード・納品送付
- 依頼者への納品通知
- 依頼者による納品写真の閲覧・承認
- 依頼者による写真のダウンロード（承認後）
- 納品に対するやり直し要求（承認前のみ）

### この機能に含まないもの

- 写真のウォーターマーク処理（フェーズ2）
- 写真販売（フェーズ2）
- 写真の編集機能

---

## 4. ユーザーアクション

### ユーザーができること（フォトグラファー）

- 撮影写真をアップロードして依頼者に送付する
- 承認前であれば写真を差し替える

### ユーザーができること（依頼者）

- 納品写真を閲覧する
- 写真を承認する
- 写真をダウンロードする（承認後）
- やり直しを要求する（承認前のみ）

### ユーザーができないこと

- 承認後にやり直しを要求する（運営への申告で対応）
- 写真の無断二次利用（利用規約で規定）

---

## 5. 正常系フロー

### 写真の納品（フォトグラファー）

1. 撮影完了後、フォトグラファーが納品画面を開く
2. 納品する写真を選択してアップロードする
3. 「納品する」ボタンをタップ
4. 依頼者に納品通知が送信される（通知）
5. 依頼のステータスが「納品済み・確認待ち」となる

### 写真の承認（依頼者）

1. 依頼者が納品通知を受け取る（通知）
2. 納品写真一覧を閲覧する
3. 「承認する」ボタンをタップ
4. 決済が確定し、フォトグラファーへの売上が計上される（エスクロー決済）
5. 写真のダウンロードが可能になる

### 写真のダウンロード（依頼者）

1. 依頼者が承認済みの写真一覧を開く
2. ダウンロードしたい写真を選択する（一括ダウンロードも可）
3. 写真がダウンロードされる

---

## 6. 例外・エラーケース

| ケース                               | 表示・挙動                                                 |
| ------------------------------------ | ---------------------------------------------------------- |
| アップロードファイルがサイズ上限超過 | 「ファイルサイズが上限を超えています」と表示               |
| 非対応フォーマットのファイル         | 「JPEG・PNG・WEBPのみ対応しています」と表示                |
| 依頼者が一定期間内に承認しない       | 自動承認して決済を確定させる                               |
| 依頼者がやり直しを要求した           | フォトグラファーへやり直し要求通知を送信し、再納品フローへ |
| 承認後にダウンロードリンクが期限切れ | 再ダウンロードのリクエストを受け付ける（対応方法は未定）   |

---

## 7. ビジネスルール

- フォトグラファーは依頼確定後のみ納品できる
- 依頼者の承認をもって決済が確定する（エスクロー決済）
- 納品写真のダウンロードは承認後のみ可能
- 納品写真のダウンロードリンクには有効期限を設ける（期間は未決定）

---

## 8. 関連仕様

- エスクロー決済（承認後に決済確定）
- 通知（納品・承認の通知）
- 運営管理（納品トラブル・返金対応）
