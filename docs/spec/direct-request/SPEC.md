# 機能仕様：指名型依頼

## 1. 機能概要

### 機能名

指名型依頼

### 機能の目的

依頼者が特定のフォトグラファーへ直接撮影依頼を送り、フォトグラファーが承認・拒否できるようにする。

### この機能で解決する課題

- 気に入ったフォトグラファーに直接依頼できることで、依頼者の選択の自由度を高める

---

## 2. 対象ユーザー

### 主な利用者

- 依頼者（依頼を送る側）
- フォトグラファー（依頼を受け取り、承認・拒否する側）

### 利用シーン

- 依頼者がポートフォリオを見て気に入ったフォトグラファーへ直接依頼するとき
- フォトグラファーが受け取った依頼内容を確認し、承認・拒否するとき

---

## 3. 機能スコープ

### この機能に含むもの

- 撮影依頼の作成・送信（撮影シーン・希望日時・場所・予算・補足事項）
- フォトグラファーによる依頼の確認・承認・拒否
- 依頼ステータスの管理（申請中・承認済み・拒否・キャンセル）

### この機能に含まないもの

- 公募型依頼（公募型依頼・提案比較・選択で対応）
- 依頼確定後の決済処理（エスクロー決済で対応）
- チャット（チャットで対応）

---

## 4. ユーザーアクション

### ユーザーができること（依頼者）

- 撮影依頼を作成・送信する
- 送信した依頼のステータスを確認する
- 承認前の依頼をキャンセルする

### ユーザーができること（フォトグラファー）

- 受け取った依頼の内容を確認する
- 依頼を承認する
- 依頼を拒否する（理由の入力は任意）

### ユーザーができないこと

- 承認済みの依頼を一方的にキャンセルする（キャンセルポリシーに従う）
- ログインせずに依頼を送信する

---

## 5. 正常系フロー

### 依頼の送信（依頼者）

1. 依頼者がフォトグラファー詳細ページの「依頼する」ボタンをタップ
2. 撮影シーン・希望日時・場所・予算・補足事項を入力する
3. 入力内容を確認し「依頼を送る」ボタンをタップ
4. フォトグラファーへ依頼通知が送信される（通知）
5. 依頼のステータスが「申請中」となる

### 依頼の承認（フォトグラファー）

1. フォトグラファーが依頼通知を受け取る（通知）
2. 依頼内容（シーン・日時・場所・予算）を確認する
3. 「承認する」ボタンをタップ
4. 依頼のステータスが「承認済み」となる
5. 依頼者に承認通知が送信され、エスクロー決済へ進む（エスクロー決済）

### 依頼の拒否（フォトグラファー）

1. フォトグラファーが依頼内容を確認する
2. 「拒否する」ボタンをタップし、理由を入力する（任意）
3. 依頼者に拒否通知が送信される（通知）
4. 依頼のステータスが「拒否」となる

---

## 6. 例外・エラーケース

| ケース                                           | 表示・挙動                                           |
| ------------------------------------------------ | ---------------------------------------------------- |
| 指定した日時にフォトグラファーの空きがない       | 「選択した日時はすでに予約済みです」と表示し送信不可 |
| 依頼送信後に対象フォトグラファーが退会・停止した | 依頼が自動キャンセルされ、依頼者に通知する           |
| フォトグラファーが一定期間内に返答しない         | 依頼が自動キャンセルされ、依頼者に通知する           |

---

## 7. ビジネスルール

- 依頼者はログイン必須
- 1回の依頼には、1つの希望日時のみ指定できる
- フォトグラファーが承認した後のキャンセルはキャンセルポリシーに従う

---

## 8. 関連仕様

- フォトグラファー検索・閲覧（依頼のエントリーポイント）
- スケジュール管理（空き日時の確認・確定後のブロック）
- チャット（依頼前後のコミュニケーション）
- エスクロー決済（承認後の決済処理）
- 通知（依頼・承認・拒否の通知）
