# 機能仕様：運営管理

## 1. 機能概要

### 機能名

運営管理

### 機能の目的

運営スタッフがユーザー停止、通報対応、案件トラブル対応を行い、サービスの安全性を維持できるようにする。

### この機能で解決する課題

- 問題ユーザーや不適切コンテンツを放置するとサービスの信頼性が下がる
- 案件やチャットのトラブル時に、運営が履歴を確認できる必要がある

---

## 2. 対象ユーザー

### 主な利用者

- 運営スタッフ
- 管理者

### 利用シーン

- 通報が届いた時
- ユーザーを停止、再開したい時
- 案件トラブルの状況確認が必要な時

---

## 3. 機能スコープ

### この機能に含むもの

- 管理者ログイン済みユーザーだけが見られる管理画面
- ユーザー検索、詳細閲覧
- 通報一覧、通報詳細、対応記録
- ユーザー停止、再開
- 案件、チャット履歴の参照
- 管理操作の監査ログ

### この機能に含まないもの

- 一般ユーザーによる管理画面アクセス
- 自動モデレーション
- アプリ内チャットへの管理者投稿

---

## 4. 通報データ

一般ユーザー向け導線で作成される通報には以下を含める。

| 項目         | 必須 | 備考                                    |
| ------------ | ---- | --------------------------------------- |
| 通報対象種別 | 必須 | ユーザー / 案件 / メッセージ            |
| 通報対象 ID  | 必須 | 対象レコード                            |
| 通報理由     | 必須 | スパム / 不適切内容 / 外部誘導 / その他 |
| 詳細コメント | 任意 | 0〜1000文字                             |
| 通報者 ID    | 必須 | 内部参照のみ                            |

---

## 5. ユーザーアクション

### 管理者ができること

- ユーザーを表示名、メールアドレス、状態で検索する
- ユーザー詳細でプロフィール、ポートフォリオ、案件履歴、通報履歴を確認する
- 通報内容を確認し、対応結果を記録する
- ユーザーを停止、再開する
- 必要に応じて案件をキャンセルする

### ユーザーができないこと

- 一般ユーザーが管理画面に入る
- 管理者が監査ログを残さずに停止処理する

---

## 6. 正常系フロー

### ユーザー停止

1. 管理者が対象ユーザーを検索する
2. プロフィール、案件履歴、通報履歴、チャット履歴を確認する
3. 停止理由を入力して停止を実行する
4. 対象ユーザーをログイン不可にする
5. 公開プロフィール、公開作品を検索結果から除外する
6. 必要に応じて募集中、進行中案件を `キャンセル` に更新する
7. 停止通知を送信し、監査ログを保存する

### 通報対応

1. 管理者が通報一覧を開く
2. 通報理由、関連ユーザー、案件、メッセージを確認する
3. 対応結果を `問題なし`、`警告`、`停止`、`案件キャンセル` のいずれかで記録する
4. 対応コメントを残し、対応済みへ更新する

---

## 7. 表示仕様

- ユーザー一覧では `通常 / 停止中` の状態を表示する
- 通報一覧では未対応を先頭表示する
- ユーザー詳細から関連案件、関連チャットへドリルダウンできる
- 監査ログには実行者、実行日時、対象、操作内容、理由を保持する

---

## 8. 例外・エラーケース

| ケース                                     | 表示・挙動                                         |
| ------------------------------------------ | -------------------------------------------------- |
| 停止済みユーザーを再度停止しようとした     | 追加処理せず現在状態を表示する                     |
| 権限のないユーザーが管理画面へアクセスした | 403 とし、一般画面へ遷移させる                     |
| 通報対象が既に削除、非公開化されていた     | 参照不能であることを表示し、履歴のみ閲覧可能にする |
| 停止処理中に一部案件更新が失敗した         | リトライ対象として記録し、管理者へ警告を表示する   |

---

## 9. ビジネスルール

- 管理画面へのアクセスは管理者ロールのみ
- 停止はログイン禁止と公開停止を同時に意味する
- 停止解除した場合、検索掲載はプロフィール条件を満たしている場合のみ復帰する
- 管理操作はすべて監査ログに残す
- 通報者の情報は一般ユーザーへ開示しない
