# 機能仕様：新規登録・ログイン

## 1. 機能概要

### 機能名

新規登録・ログイン

### 実装ステータス

現在のコードベースでは未実装。認証基盤は Supabase Auth へ移行予定であり、本仕様はその実装方針を定義する。

### 機能の目的

Google アカウントを利用して、ユーザーが安全かつ短時間で PhotoMatch に登録・ログインできるようにする。

### この機能で解決する課題

- メールアドレス、パスワード管理を不要にし、登録障壁を下げる
- 同一アカウントで依頼者、フォトグラファーの両方を利用できる
- 停止済みアカウントの利用を防ぎ、運営管理と整合する

---

## 2. 対象ユーザー

### 主な利用者

- PhotoMatch を初めて利用するユーザー
- ログアウト後に再度利用するユーザー
- 認証必須画面へ遷移した未ログインユーザー

### 利用シーン

- 初回登録時
- 再ログイン時
- 依頼、提案、フォロー、チャットなど認証必須機能を使う時

---

## 3. 機能スコープ

### この機能に含むもの

- Google OAuth による新規登録
- Google OAuth によるログイン
- 初回登録時のユーザーアカウント作成
- Google から取得した表示名、プロフィール画像、メールアドレスの初期保存
- 利用規約、プライバシーポリシーへの初回同意
- セッション管理
- ログアウト
- 未認証ユーザーのログイン画面への誘導

### この機能に含まないもの

- メールアドレス、パスワード認証
- Google 以外の OAuth
- 本人確認書類の提出
- 退会申請
- メール通知設定

---

## 4. ユーザーアクション

### ユーザーができること

- Google アカウントで登録する
- Google アカウントでログインする
- ログイン後に直前まで見ていた画面へ戻る
- ログアウトする

### ユーザーができないこと

- Google 以外の手段で登録、ログインする
- 停止済みアカウントでログインする
- サービス内からログイン用メールアドレスを変更する

---

## 5. 正常系フロー

### 新規登録

1. ユーザーが登録画面の「Google で登録する」を押下する
2. Google 認証画面でアカウントを選択し、認可する
3. Google の `sub` を用いて既存アカウントの有無を確認する
4. 初回登録の場合、ユーザーを作成し、表示名、アバター URL、メールアドレスを初期値として保存する
5. 利用規約、プライバシーポリシーへの同意を取得する
6. セッションを開始し、プロフィール初期設定画面へ遷移する

### ログイン

1. ユーザーがログイン画面の「Google でログインする」を押下する
2. Google 認証を完了する
3. 停止状態でないことを確認する
4. セッションを開始する
5. 遷移元 URL がある場合はそこへ戻し、なければホームへ遷移する

### ログアウト

1. ユーザーがメニューから「ログアウト」を押下する
2. サービス側セッションを破棄する
3. トップページへ遷移する

---

## 6. 入出力仕様

### Google から取得して保持する項目

| 項目                 | 用途                 | 公開範囲 |
| -------------------- | -------------------- | -------- |
| Google `sub`         | ユーザー同一性の判定 | 非公開   |
| メールアドレス       | 運営連絡、内部管理   | 非公開   |
| 表示名               | 初期プロフィール値   | 公開可能 |
| プロフィール画像 URL | 初期アバター値       | 公開可能 |

### セッションに関するルール

- ログイン成功後はブラウザセッションを発行する
- 最終アクセスから30日経過でセッションを失効させる
- 停止処理が行われたユーザーの既存セッションは無効化する

---

## 7. 例外・エラーケース

| ケース                                                 | 表示・挙動                                         |
| ------------------------------------------------------ | -------------------------------------------------- |
| Google 認証画面でキャンセルした                        | 登録、ログイン画面へ戻る                           |
| Google から必要情報を取得できない                      | 「認証を完了できませんでした」と表示し再試行を促す |
| 既存アカウントと同じ Google アカウントで登録した       | 新規作成は行わず、ログインとして処理する           |
| 利用規約同意前に登録処理を進めようとした               | 同意が必要である旨を表示し進行不可とする           |
| 停止済みアカウントでログインしようとした               | ログインを拒否し、問い合わせ導線を表示する         |
| セッションが失効していた                               | 再ログイン画面へ遷移し、完了後に元画面へ戻す       |
| 認証中またはセッション開始時にサーバーエラーが発生した | エラーメッセージを表示し、再試行を促す             |

---

## 8. ビジネスルール

- Google `sub` を一意キーとして扱い、メールアドレス変更のみでは別アカウントにならない
- 初回登録時にのみ Google の表示名、画像を初期値として取り込む
- 以後のプロフィール編集はプロフィール管理機能で行う
- 認証済みであっても、必要なプロフィール入力が終わるまでは依頼、提案、フォローを実行できない
- 利用規約、プライバシーポリシーへの同意は初回登録時に必須とする
- 停止済みアカウントはログイン不可、かつ既存セッションも無効化する
