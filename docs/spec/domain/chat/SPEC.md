# 機能仕様：チャット

## 1. 機能概要

### 機能名

チャット

### 機能の目的

マッチ成立後の当事者が、撮影条件や当日の段取りをサービス内で安全に調整できるようにする。

### この機能で解決する課題

- マッチ成立後の調整手段がないと、成約後の実行に進めない
- サービス外へすぐ移動して履歴が失われると、トラブル時の確認が難しい

---

## 2. 対象ユーザー

### 主な利用者

- 指名型依頼または公募型依頼でマッチ成立した依頼者
- 採用または承認されたフォトグラファー

### 利用シーン

- 日時、待ち合わせ場所、支払い方法などを確認する時
- 撮影実施後に完了操作を進める時

---

## 3. 機能スコープ

### この機能に含むもの

- 案件に紐づく1対1チャット
- テキストメッセージ送受信
- 既読管理
- 未読件数表示
- 状態変化を示すシステムメッセージ
- 完了操作導線

### この機能に含まないもの

- グループチャット
- 画像、ファイル添付
- メッセージ編集、削除
- 音声通話、ビデオ通話

---

## 4. メッセージ仕様

| 項目     | 仕様                                 |
| -------- | ------------------------------------ |
| 本文     | 1〜2000文字                          |
| 改行     | 許可                                 |
| URL      | プレーンテキスト表示のみ             |
| 送信時刻 | 日本時間で表示                       |
| 既読     | 相手がチャット画面を開いた時点で付与 |

---

## 5. ユーザーアクション

### ユーザーができること

- メッセージを送信する
- 受信メッセージを閲覧する
- 既読状態を確認する
- 案件完了後に完了操作を行う
- 不適切な相手やメッセージを通報する

### ユーザーができないこと

- マッチ成立前にチャットを始める
- 完了、キャンセル済み案件で新規メッセージを送る
- メッセージを編集、削除する

---

## 6. 正常系フロー

### チャット開始

1. 指名型依頼の承認、または公募提案の採用でマッチ成立する
2. 案件専用のチャットルームを作成する
3. 当事者は案件詳細または通知からチャット画面へ遷移できる

### メッセージ送受信

1. 当事者がメッセージを入力して送信する
2. メッセージを保存し、相手へ通知する
3. この案件で最初のユーザーメッセージ送信時に状態を `進行中` に更新する
4. 相手がチャット画面を開くと既読になる

### 完了操作

1. 撮影と支払いが終了したら、当事者が「完了に進む」を押下する
2. 片側の操作で `完了待ち` に更新する
3. 双方の完了操作、または7日経過で `完了` に更新する
4. 状態更新をシステムメッセージと通知で知らせる

---

## 7. 表示仕様

- メッセージは時系列昇順で表示する
- 画面上部に案件のジャンル、相手名、現在の案件状態を表示する
- システムメッセージとして `マッチ成立`、`進行中`、`完了待ち`、`完了`、`キャンセル` を表示する
- 未読件数はチャット一覧、通知バッジに反映する
- 完了、キャンセル後は履歴閲覧のみ許可し、入力欄は非表示にする

---

## 8. 例外・エラーケース

| ケース                                        | 表示・挙動                   |
| --------------------------------------------- | ---------------------------- |
| 空メッセージを送信しようとした                | 送信ボタンを非活性にする     |
| 2000文字を超える                              | 上限超過を表示し送信不可     |
| ネットワークエラーで送信失敗                  | 再送導線を表示する           |
| マッチ成立前にチャット URL へ直接アクセスした | 閲覧不可として案件詳細へ戻す |
| 完了、キャンセル済み案件で送信しようとした    | 送信不可であることを表示する |

---

## 9. ビジネスルール

- チャットルームは案件ごとに1つだけ作成する
- 当事者以外はアクセスできない
- 管理者は通報調査時に閲覧できるが、投稿者として参加しない
- メッセージ本文に外部連絡先を記載すること自体は禁止しないが、通報時の判断対象とする
- 完了、キャンセル後のチャット履歴は90日間保持する
