# 機能仕様：指名型依頼

## 1. 機能概要

### 機能名

指名型依頼

### 機能の目的

依頼者が特定のフォトグラファーへ直接依頼を送り、承認後すぐに調整へ進めるようにする。

### この機能で解決する課題

- 気に入ったフォトグラファーへ最短で依頼したいニーズに応える
- 公募せずに1対1で相談を始めたいケースを扱えるようにする

---

## 2. 対象ユーザー

### 主な利用者

- 依頼者
- 依頼を受けるフォトグラファー

### 利用シーン

- 作品やプロフィールを見て、この人に頼みたいと判断した時
- フォトグラファーが依頼内容を見て受諾可否を判断する時

---

## 3. 機能スコープ

### この機能に含むもの

- 依頼作成、送信
- フォトグラファーによる承認、辞退
- 承認待ち期限の管理
- マッチ成立後のチャット導線
- 完了、キャンセルの状態管理

### この機能に含まないもの

- 公募への提案募集
- アプリ内決済
- 契約書締結

---

## 4. 依頼項目

| 項目         | 必須 | 形式               | 備考                   |
| ------------ | ---- | ------------------ | ---------------------- |
| 撮影ジャンル | 必須 | 単一選択           | 共通ジャンル定義を使用 |
| 希望撮影日   | 必須 | 日付または日時     | 第1希望のみ            |
| 撮影エリア   | 必須 | 都道府県、市区町村 | 詳細住所は不要         |
| 予算         | 必須 | 円単位の整数       | 税込み総額目安         |
| 補足事項     | 任意 | 0〜1000文字        | 要望、実費扱いなど     |

---

## 5. ユーザーアクション

### 依頼者ができること

- 依頼を作成して送信する
- 送信済み依頼の状態を確認する
- 承認前の依頼をキャンセルする
- マッチ成立後にキャンセル理由付きでキャンセルする
- 完了操作を行う

### フォトグラファーができること

- 依頼内容を確認する
- 依頼を承認する
- 依頼を辞退する
- マッチ成立後にキャンセル理由付きでキャンセルする
- 完了操作を行う

### ユーザーができないこと

- 未ログインで依頼を送る
- 自分自身へ依頼する
- 承認待ち中に同一相手へ重複依頼を送る

---

## 6. 正常系フロー

### 依頼送信

1. 依頼者がフォトグラファー詳細ページで「依頼する」を押下する
2. 依頼項目を入力して送信する
3. 依頼は `募集中` になる
4. フォトグラファーへ通知する

### 承認

1. フォトグラファーが依頼内容を確認する
2. 「承認する」を押下する
3. 状態を `マッチ成立` に更新する
4. 案件専用チャットルームを作成する
5. 依頼者へ承認通知を送る

### 辞退

1. フォトグラファーが依頼内容を確認する
2. 「辞退する」を押下する
3. 任意で理由を入力する
4. 状態を `キャンセル` に更新し、理由区分を `フォトグラファー辞退` とする
5. 依頼者へ通知する

### 進行、完了

1. マッチ成立後、どちらかが最初のメッセージを送る
2. 状態を `進行中` に更新する
3. 撮影、支払いが終わったら当事者が完了操作を行う
4. 片側の操作で `完了待ち`、双方完了で `完了` とする

---

## 7. 期限と状態遷移

- 依頼送信後72時間以内に承認または辞退がない場合、自動で `キャンセル` にする
- 自動キャンセル時の理由区分は `承認期限切れ` とする
- `マッチ成立` 後の最初のチャット送信で `進行中` に遷移する
- `完了待ち` で7日経過しても相手が完了操作しない場合、自動で `完了` にする

---

## 8. 例外・エラーケース

| ケース                               | 表示・挙動                                           |
| ------------------------------------ | ---------------------------------------------------- |
| 依頼先が停止、退会状態になった       | 送信不可、または自動キャンセルとして依頼者へ通知する |
| 同一相手に承認待ち依頼が既にある     | 新規送信を拒否し、既存依頼へ誘導する                 |
| 予算が未入力または0円以下            | バリデーションエラーとして保存不可                   |
| 補足事項が1000文字を超える           | 保存不可とし、上限超過を表示する                     |
| マッチ成立前にチャットへ入ろうとした | 閲覧不可として案件詳細へ戻す                         |
| マッチ成立後にキャンセルした         | 状態を `キャンセル` にし、相手へ通知する             |

---

## 9. ビジネスルール

- 依頼送信には依頼者プロフィールの必須項目入力が必要
- 依頼先は公開条件を満たしたフォトグラファーに限る
- 詳細住所や連絡先は依頼フォームでは収集しない
- 承認後の金額や条件変更はチャットで調整し、依頼レコードの初期値は履歴として保持する
- キャンセル料の算定や徴収はアプリで扱わない
