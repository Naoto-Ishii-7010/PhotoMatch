# 機能仕様：案件検索（フォトグラファー向け）

## 1. 機能概要

### 機能名

案件検索

### 機能の目的

フォトグラファーが公募中の撮影案件を効率的に見つけ、提案すべき案件を判断できるようにする。

### この機能で解決する課題

- 条件に合う公募を一覧で見つけにくい
- 提案前に必要な情報が不足し、ミスマッチが起きやすい

---

## 2. 対象ユーザー

### 主な利用者

- 公募案件へ提案したいフォトグラファー

### 利用シーン

- 空き日程に合う案件を探したい時
- 得意ジャンルや移動可能エリアで案件を絞りたい時

---

## 3. 機能スコープ

### この機能に含むもの

- 公募案件一覧の閲覧
- 条件による絞り込み
- 案件詳細の閲覧
- 案件詳細から提案送信導線への遷移

### この機能に含まないもの

- 提案送信自体の保存処理
- 指名型依頼の閲覧
- 依頼者向けの公募管理

---

## 4. 利用前提

案件検索を利用するには以下を満たすこと。

- ログイン済みである
- フォトグラファー公開条件を満たしている
- 停止状態でない

条件未達の場合、一覧へは入れずプロフィール設定またはポートフォリオ追加へ誘導する。

---

## 5. ユーザーアクション

### ユーザーができること

- 公募案件一覧を閲覧する
- エリア、ジャンル、予算、希望撮影日で絞り込む
- 案件詳細で依頼内容と依頼者プロフィールを確認する
- 「提案する」から公募提案フローへ進む

### ユーザーができないこと

- 未ログインで一覧を閲覧する
- 自分が投稿した公募を一覧表示する
- 締切済み、マッチ成立済み、キャンセル済みの公募へ提案する

---

## 6. 正常系フロー

1. フォトグラファーが案件検索画面を開く
2. 条件を指定して案件一覧を閲覧する
3. 気になる案件を開き、依頼内容、撮影エリア、予算、補足事項、募集締切を確認する
4. 提案可能な案件であれば「提案する」を押下する
5. 公募型依頼の提案送信フローへ遷移する

---

## 7. 検索条件と表示仕様

### 絞り込み条件

| 項目       | 入力形式 | 備考                                                               |
| ---------- | -------- | ------------------------------------------------------------------ |
| エリア     | 単一選択 | 都道府県                                                           |
| ジャンル   | 複数選択 | 共通ジャンル定義を使用                                             |
| 予算       | 単一選択 | 下限なし / 3,000円以上 / 5,000円以上 / 10,000円以上 / 20,000円以上 |
| 希望撮影日 | 日付範囲 | 指定期間に重なる案件を対象                                         |
| 並び順     | 単一選択 | 新着順 / 予算が高い順 / 締切が近い順                               |

### 案件カード表示項目

- 撮影ジャンル
- 撮影エリア（都道府県、市区町村）
- 希望撮影日
- 予算
- 補足事項の先頭50文字
- 募集締切日時
- 投稿日時
- 現在の提案件数
- 自分が提案済みかどうか

### 詳細ページ表示項目

- 上記カード情報の全文
- 依頼者の表示名、アバター
- 依頼者の自己紹介
- 正確な住所は非表示

### ページング

- 1回の取得件数は20件
- 一覧は無限スクロールで追加読み込みする

---

## 8. 例外・エラーケース

| ケース                       | 表示・挙動                                           |
| ---------------------------- | ---------------------------------------------------- |
| 条件に一致する案件がない     | 条件見直しメッセージとリセット導線を表示する         |
| 募集中案件が全体で存在しない | 「現在募集中の案件はありません」と表示する           |
| 既に提案済みの案件を開いた   | 「提案済みです」を表示し、提案ボタンを非活性にする   |
| 締切後に詳細を開いた         | 提案不可であることを表示し、提案ボタンを非活性にする |
| ネットワークエラー           | 再試行ボタンを表示する                               |

---

## 9. ビジネスルール

- 表示対象は `募集中` または `提案中` かつ募集締切前の公募に限る
- 自分が依頼者として作成した公募は表示しない
- 自分が提案済みの案件にも閲覧はできるが、同一提案の重複送信はできない
- 正確な待ち合わせ場所、連絡先は詳細ページで表示しない
- 停止済み依頼者の公募は一覧から除外する
