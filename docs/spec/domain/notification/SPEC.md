# 機能仕様：通知

## 1. 機能概要

### 機能名

通知

### 機能の目的

案件進行に必要なイベントを見逃さないよう、プッシュ通知とアプリ内通知で即時に知らせる。

### この機能で解決する課題

- 依頼、提案、メッセージの見落としを防ぐ
- 画面を開いていない間も重要な状態変化を伝える

---

## 2. 対象ユーザー

### 主な利用者

- 登録済みユーザー
- 依頼、提案、チャットに関与する当事者
- フォロー通知を受けるフォトグラファー

### 利用シーン

- 新しい依頼、提案、メッセージが届いた時
- 案件の状態が変わった時
- フォローや停止などアカウント関連のイベントが起きた時

---

## 3. 機能スコープ

### この機能に含むもの

- プッシュ通知
- アプリ内通知一覧
- 未読件数表示
- 通知既読管理
- 通知タップから対象画面への遷移

### この機能に含まないもの

- メール通知
- SMS 通知
- 通知種別ごとのユーザー設定

---

## 4. 通知イベント一覧

| イベント                                   | 通知対象         | 遷移先                   |
| ------------------------------------------ | ---------------- | ------------------------ |
| 指名型依頼を受け取った                     | フォトグラファー | 指名依頼詳細             |
| 指名型依頼が承認された                     | 依頼者           | 案件チャット             |
| 指名型依頼が辞退された                     | 依頼者           | 指名依頼詳細             |
| 指名型依頼が承認期限切れでキャンセルされた | 依頼者           | 指名依頼詳細             |
| 公募へ提案が届いた                         | 依頼者           | 提案一覧                 |
| 提案が採用された                           | フォトグラファー | 案件チャット             |
| 提案が不採用になった                       | フォトグラファー | 公募詳細                 |
| 公募が締切、または期限切れで終了した       | 依頼者           | 公募詳細                 |
| 新規メッセージを受信した                   | 相手ユーザー     | 該当チャット             |
| 案件が完了待ちになった                     | 当事者           | 該当チャット             |
| 案件が完了した                             | 当事者           | 該当チャット             |
| 案件がキャンセルされた                     | 当事者           | 案件詳細                 |
| フォローされた                             | フォトグラファー | 自分の詳細ページ         |
| アカウント停止された                       | 対象ユーザー     | お知らせ、問い合わせ導線 |

---

## 5. ユーザーアクション

### ユーザーができること

- 通知一覧を開く
- 通知を既読にする
- 通知から対象画面へ遷移する

### ユーザーができないこと

- 通知種別ごとに ON/OFF を切り替える
- 通知本文を編集する

---

## 6. 正常系フロー

1. 対象イベントが発生する
2. 通知レコードを生成する
3. アプリ内通知一覧へ追加する
4. 端末がプッシュ許可済みであればプッシュ通知を送る
5. ユーザーが通知一覧またはプッシュから対象画面へ遷移する
6. 遷移または一覧表示時に既読化する

---

## 7. 表示仕様

- 通知一覧は新着順で表示する
- 未読通知は強調表示する
- 通知本文は種別ごとの定型文とし、必要に応じて相手名や案件ジャンルを差し込む
- 一覧では最新90日分を保持する
- 同一画面内で連続発生した同種通知は個別レコードとして保持する

---

## 8. 例外・エラーケース

| ケース                                 | 表示・挙動                                   |
| -------------------------------------- | -------------------------------------------- |
| プッシュ通知が未許可                   | アプリ内通知一覧のみ表示する                 |
| プッシュ送信に失敗した                 | リトライし、失敗してもアプリ内通知は保持する |
| 通知先の案件やユーザーが停止、削除済み | 遷移不可メッセージを表示し、通知一覧へ戻す   |

---

## 9. ビジネスルール

- イベント発生時にアプリ内通知は必ず生成する
- プッシュ通知は端末許可状況に依存する
- 自分自身の操作に対する通知は送らない
- 既読状態はユーザー単位で保持する
