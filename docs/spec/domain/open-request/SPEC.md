# 機能仕様：公募型依頼・提案比較・選択

## 1. 機能概要

### 機能名

公募型依頼・提案比較・選択

### 機能の目的

依頼者が撮影希望を公募として公開し、複数提案の比較を通じて最適なフォトグラファーを選べるようにする。

### この機能で解決する課題

- 誰に依頼すべきか決まっていない依頼者でも候補を集められる
- フォトグラファーが自発的に案件を取りに行ける

---

## 2. 対象ユーザー

### 主な利用者

- 公募を投稿する依頼者
- 公募へ提案するフォトグラファー

### 利用シーン

- 条件に合う人を比較して選びたい時
- 新規顧客を獲得したいフォトグラファーが案件を探す時

---

## 3. 機能スコープ

### この機能に含むもの

- 公募投稿
- 提案送信、提案取り下げ
- 提案一覧表示と比較
- 採用する提案の選択
- マッチ成立後のチャット導線
- 募集締切と未選択終了の管理

### この機能に含まないもの

- 指名型依頼
- アプリ内決済
- 提案への個別コメントスレッド

---

## 4. 公募項目と提案項目

### 公募項目

| 項目         | 必須 | 形式               | 備考                       |
| ------------ | ---- | ------------------ | -------------------------- |
| 撮影ジャンル | 必須 | 単一選択           | 共通ジャンル定義を使用     |
| 希望撮影日   | 必須 | 日付または日時     | 代表となる希望日           |
| 撮影エリア   | 必須 | 都道府県、市区町村 | 詳細住所は不要             |
| 予算         | 必須 | 円単位の整数       | 税込み総額目安             |
| 補足事項     | 任意 | 0〜1000文字        | 依頼背景、条件など         |
| 募集締切日時 | 必須 | 日時               | 投稿時点から最大14日先まで |

### 提案項目

| 項目           | 必須 | 形式         | 備考                   |
| -------------- | ---- | ------------ | ---------------------- |
| 提案金額       | 必須 | 円単位の整数 | 税込み総額目安         |
| 提案メッセージ | 必須 | 1〜1000文字  | 対応内容、実費扱いなど |

---

## 5. ユーザーアクション

### 依頼者ができること

- 公募を投稿する
- 投稿中の公募を確認する
- 提案一覧を比較する
- 提案を1件選択する
- 選択前の公募をキャンセルする
- マッチ成立後にキャンセル理由付きでキャンセルする
- 完了操作を行う

### フォトグラファーができること

- 公募を閲覧する
- 公募に提案する
- 採用前の提案を取り下げる
- マッチ成立後にキャンセル理由付きでキャンセルする
- 完了操作を行う

### ユーザーができないこと

- 同一公募へ同時に複数提案を保持する
- 自分自身が投稿した公募へ提案する
- 締切後に新規提案する

---

## 6. 正常系フロー

### 公募投稿

1. 依頼者が公募作成画面を開く
2. 公募項目を入力して投稿する
3. 状態を `募集中` にする
4. 案件検索に掲載する

### 提案送信

1. フォトグラファーが案件検索または公募詳細から提案画面を開く
2. 提案金額と提案メッセージを入力して送信する
3. 最初の提案で状態を `提案中` にする
4. 依頼者へ通知する

### 提案選択

1. 依頼者が提案一覧を開く
2. 各提案の金額、メッセージ、プロフィール、ポートフォリオを比較する
3. 1件を選択して確定する
4. 状態を `マッチ成立` にする
5. 採用されたフォトグラファーとのチャットルームを作成する
6. 不採用提案は自動で終了し、落選通知を送る

### 進行、完了

1. マッチ成立後、最初のチャット送信で `進行中` に遷移する
2. 撮影、支払い完了後に当事者が完了操作する
3. 片側の操作で `完了待ち`、双方完了で `完了` とする

---

## 7. 締切と提案ルール

- 募集締切日時までは新規提案を受け付ける
- 締切後は新規提案不可とし、既存提案の比較と選択のみ可能とする
- 締切から72時間以内に依頼者が提案を選ばない場合、公募は `キャンセル` となり、理由区分を `募集期限切れ` とする
- 同一フォトグラファーは同一公募に同時に1件まで提案可能
- 提案取り下げ後、締切前であれば再提案できる

---

## 8. 例外・エラーケース

| ケース                                   | 表示・挙動                               |
| ---------------------------------------- | ---------------------------------------- |
| 同一公募へ重複提案しようとした           | 「すでに提案中です」と表示し送信不可     |
| 締切日時が過去または14日超過             | バリデーションエラーとして保存不可       |
| 提案が0件のまま締切を迎えた              | `キャンセル` にし、依頼者へ通知する      |
| 依頼者が提案選択前に公募をキャンセルした | 提案済みフォトグラファーへ通知する       |
| 採用済み提案を取り下げようとした         | 取り下げ不可とし、案件詳細へ誘導する     |
| マッチ成立後にキャンセルした             | 状態を `キャンセル` にし、相手へ通知する |

---

## 9. ビジネスルール

- 公募投稿には依頼者プロフィールの必須項目入力が必要
- 提案にはフォトグラファー公開条件の達成が必要
- 正確な住所や連絡先は公募詳細には表示しない
- 提案比較では金額だけでなくプロフィール、作品も同時に見られるようにする
- 採用後の条件調整はチャットで行い、採用時の提案内容は履歴として保持する
- キャンセル料の算定や徴収はアプリで扱わない
