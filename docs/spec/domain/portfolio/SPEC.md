# 機能仕様：ポートフォリオ管理

## 1. 機能概要

### 機能名

ポートフォリオ管理

### 機能の目的

フォトグラファーが自分の作品を公開し、撮影スタイルや得意ジャンルを依頼者へ伝えられるようにする。

### この機能で解決する課題

- 依頼者が事前に写真の雰囲気を把握できず、依頼判断がしづらい
- フォトグラファーが検索掲載に必要な実績を示せない

---

## 2. 対象ユーザー

### 主な利用者

- フォトグラファー

### 利用シーン

- 新しい作品を公開したい時
- 検索掲載条件を満たしたい時
- 古い作品を非公開、削除して整理したい時

---

## 3. 機能スコープ

### この機能に含むもの

- 作品画像のアップロード
- タイトル、説明文、ジャンル、ハッシュタグの設定
- 公開、非公開の切り替え
- 作品削除
- 管理一覧のグリッド表示

### この機能に含まないもの

- 動画アップロード
- 作品販売
- 画像の高度な編集機能
- 閲覧数分析

---

## 4. 作品項目

| 項目         | 必須 | 形式                        | 備考                     |
| ------------ | ---- | --------------------------- | ------------------------ |
| 作品画像     | 必須 | JPEG / PNG / WEBP、15MB以下 | 1投稿につき1枚           |
| タイトル     | 必須 | 1〜40文字                   | 一覧、検索対象           |
| 説明文       | 任意 | 0〜200文字                  | 検索対象                 |
| ジャンル     | 必須 | 単一選択                    | 検索仕様のジャンルを使用 |
| ハッシュタグ | 任意 | 0〜5件、各20文字以内        | `#` なしで保存           |
| 公開状態     | 必須 | 公開 / 非公開               | 下書き保存相当として扱う |

### 投稿上限

- 1ユーザーあたり最大30件

---

## 5. ユーザーアクション

### ユーザーができること

- 作品画像をアップロードする
- タイトル、説明文、ジャンル、ハッシュタグを設定する
- 公開、非公開を切り替える
- 作品を削除する
- 作品一覧を確認する

### ユーザーができないこと

- 他ユーザーの作品を管理する
- 1投稿に複数画像を登録する
- 動画や GIF を投稿する

---

## 6. 正常系フロー

### 作品追加

1. フォトグラファーがポートフォリオ管理画面を開く
2. 「作品を追加」を押下する
3. 画像を選択し、タイトル、説明文、ジャンル、ハッシュタグを入力する
4. 公開または非公開を選んで保存する
5. 作品が一覧に反映される
6. 公開作品の場合、検索掲載条件と検索インデックスを更新する

### 公開切り替え

1. 一覧から対象作品を選択する
2. 公開または非公開へ切り替える
3. 公開状態に応じて検索表示を更新する

### 削除

1. 対象作品を開く
2. 「削除する」を押下する
3. 確認ダイアログで確定する
4. 一覧と検索結果から削除する

---

## 7. 表示仕様

- 管理一覧は新着順のグリッド表示とする
- フォトグラファー詳細ページでは、公開作品のみを表示する
- 検索結果で使う代表作品は新着の公開作品から最大3件とする
- 作品詳細の個別ページは MVP では設けず、作品タップ時はフォトグラファー詳細ページへ遷移する

---

## 8. 例外・エラーケース

| ケース                                     | 表示・挙動                                       |
| ------------------------------------------ | ------------------------------------------------ |
| 画像が15MBを超える                         | 「ファイルサイズが上限を超えています」と表示する |
| 非対応形式の画像                           | 「JPEG・PNG・WEBP のみ対応しています」と表示する |
| タイトル未入力                             | 保存不可とし、入力を促す                         |
| ジャンル未選択                             | 保存不可とし、入力を促す                         |
| ハッシュタグが6件以上                      | 6件目以降は入力不可とする                        |
| 作品数が30件に達している                   | 新規追加不可とし、削除または非公開化を案内する   |
| ネットワークエラーでアップロードに失敗した | エラーを表示し、再試行を促す                     |
| 禁止コンテンツが含まれると判断された       | 公開を拒否し、ガイドライン確認を促す             |

---

## 9. ビジネスルール

- 公開作品のみ検索対象とする
- 非公開作品は本人以外に表示しない
- ハッシュタグは保存時に `#` を除去し、表示時のみ `#` を付与する
- 作品画像や説明文に個人情報、連絡先、著作権侵害コンテンツを含めてはならない
- 公開ポートフォリオが1件以上あることが、フォトグラファー検索掲載の必須条件になる
- 削除した作品は一般公開から即時除外する
