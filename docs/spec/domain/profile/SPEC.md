# 機能仕様：プロフィール管理

## 1. 機能概要

### 機能名

プロフィール管理

### 機能の目的

ユーザーが公開プロフィールと活動情報を設定し、相手に安心して依頼、提案してもらえる状態を作る。

### この機能で解決する課題

- 相手の人物像や活動エリアが見えず、依頼判断がしづらい
- 検索や案件提案に必要なプロフィール情報の管理場所が不明確になりやすい

---

## 2. 対象ユーザー

### 主な利用者

- 登録済みのすべてのユーザー
- フォトグラファーとして公開活動を行うユーザー

### 利用シーン

- 新規登録直後の初期設定時
- 表示名、自己紹介、活動エリアを更新したい時
- フォトグラファーとして検索掲載条件を満たしたい時

---

## 3. 機能スコープ

### この機能に含むもの

- 表示名の設定、変更
- アバター画像の設定、変更
- 自己紹介文の設定、変更
- 活動エリアの設定
- 対応ジャンルの設定
- フォトグラファー公開設定の確認

### この機能に含まないもの

- ポートフォリオ画像の管理
- 依頼、提案の履歴管理
- 銀行口座、支払い情報の管理
- 外部 SNS 連携

---

## 4. プロフィール項目

| 項目         | 必須                   | 形式                        | 備考                       |
| ------------ | ---------------------- | --------------------------- | -------------------------- |
| 表示名       | 必須                   | 1〜30文字                   | 公開表示名として使用       |
| アバター画像 | 任意                   | JPEG / PNG / WEBP、10MB以下 | 未設定時はデフォルト画像   |
| 自己紹介文   | フォトグラファーは必須 | 0〜500文字                  | 依頼者のみ利用の場合は任意 |
| 活動都道府県 | フォトグラファーは必須 | 単一選択                    | 検索条件に使用             |
| 活動市区町村 | 任意                   | 1〜50文字                   | 詳細ページで表示可能       |
| 対応ジャンル | フォトグラファーは必須 | 1〜5件選択                  | 検索条件に使用             |

### 入力不可とする情報

- メールアドレス
- 電話番号
- 詳細住所
- 外部 SNS、外部連絡先

---

## 5. ユーザーアクション

### ユーザーができること

- 表示名を入力、変更する
- アバター画像をアップロード、変更する
- 自己紹介文を入力、変更する
- 活動エリア、対応ジャンルを設定する
- 保存後の公開状態を確認する

### ユーザーができないこと

- 他ユーザーのプロフィールを編集する
- Google に紐づくメールアドレスを変更する
- 禁止情報を公開プロフィールに掲載する

---

## 6. 正常系フロー

1. ユーザーがプロフィール編集画面を開く
2. 表示名、自己紹介、活動エリア、対応ジャンルを入力する
3. 必要に応じてアバター画像をアップロードする
4. 「保存する」を押下する
5. バリデーションに成功したらプロフィールを保存する
6. フォトグラファー条件を満たした場合、検索掲載条件の達成状況を更新する
7. 保存完了メッセージを表示する

---

## 7. 公開条件

### 依頼者として必要な条件

- 表示名が入力済みであること

### フォトグラファーとして必要な条件

- 表示名が入力済み
- 自己紹介文が入力済み
- 活動都道府県が設定済み
- 対応ジャンルが1件以上設定済み
- 公開ポートフォリオが1件以上ある

フォトグラファー条件を満たさない場合、プロフィール詳細画面は作成できても検索結果には掲載しない。

---

## 8. 例外・エラーケース

| ケース                                   | 表示・挙動                                       |
| ---------------------------------------- | ------------------------------------------------ |
| 表示名が未入力                           | 「表示名を入力してください」と表示し保存不可     |
| 表示名が30文字を超える                   | 上限超過を表示し保存不可                         |
| 自己紹介文が500文字を超える              | 入力中に文字数を表示し保存不可                   |
| 対応ジャンルを6件以上選択した            | 6件目以降は選択不可とする                        |
| アバター画像が10MBを超える               | エラーを表示しアップロード不可                   |
| 非対応形式の画像を選択した               | 「JPEG・PNG・WEBP のみ対応しています」と表示する |
| 禁止情報を含む自己紹介を保存しようとした | 保存を拒否し、修正を促す                         |

---

## 9. ビジネスルール

- 依頼者、フォトグラファーで同一プロフィールを共有する
- 検索結果に使う活動エリアと対応ジャンルはプロフィール管理で保持する
- アバター未設定時は共通のデフォルト画像を表示する
- 自己紹介や表示名に連絡先、外部サービスへの誘導を含めてはならない
- 停止済みユーザーのプロフィールは公開検索結果に表示しない
