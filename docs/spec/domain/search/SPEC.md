# 機能仕様：検索（依頼者向け）

## 1. 機能概要

### 機能名

検索（フォトグラファー検索・ポートフォリオ検索）

### 機能の目的

依頼者が自分に合うフォトグラファーや作品を見つけ、依頼まで自然につなげられるようにする。

### この機能で解決する課題

- 撮影スタイルや活動エリアが分からず、依頼先を探しにくい
- 作品起点と人物起点の両方で候補を探したい

---

## 2. 対象ユーザー

### 主な利用者

- 撮影を依頼したいユーザー
- 未ログインの閲覧ユーザー

### 利用シーン

- 条件に合うフォトグラファーを探す時
- 気に入った作品から撮影者を見つけたい時
- 詳細ページからフォローや依頼へ進みたい時

---

## 3. 機能スコープ

### この機能に含むもの

- フォトグラファー検索
- 公開ポートフォリオ検索
- フォトグラファー詳細ページの閲覧
- 詳細ページからフォロー、依頼への導線

### この機能に含まないもの

- 依頼送信自体の処理
- 案件検索
- レビュー表示

---

## 4. ジャンル定義

フォトグラファー検索、ポートフォリオ検索、案件検索で共通利用する。

| ジャンル             | 主な対象、シーン                   |
| -------------------- | ---------------------------------- |
| ポートレート         | 個人、プロフィール写真             |
| ファミリー・記念日   | 家族写真、誕生日、記念日           |
| ウェディング・婚礼   | 結婚式、前撮り、フォトウェディング |
| 七五三・節目行事     | 七五三、入学、卒業、成人式         |
| スポーツ・アクション | スポーツ、アクティビティ           |
| ペット               | 動物、ペット写真                   |
| 風景・自然           | 風景、旅行、自然                   |
| 建築・インテリア     | 建物、内装、空間                   |
| 料理・商品           | 料理、商品、物撮り                 |
| イベント・パーティー | 発表会、イベント、パーティー       |
| その他               | 上記に当てはまらない撮影           |

---

## 5. 掲載条件

検索対象となるフォトグラファーは、以下をすべて満たすユーザーのみとする。

- 停止、退会状態ではない
- 表示名、自己紹介、活動都道府県、対応ジャンルが設定済み
- 公開ポートフォリオが1件以上ある

作品検索の対象は、上記ユーザーが公開設定にしている作品のみとする。

---

## 6. ユーザーアクション

### ユーザーができること

- エリア、ジャンルでフォトグラファーを絞り込む
- キーワード、ジャンル、エリアで作品を絞り込む
- 詳細ページでプロフィール、ポートフォリオ、フォロワー数を確認する
- ログイン済みであればフォロー、指名依頼へ進む

### ユーザーができないこと

- 非公開作品を閲覧する
- 停止、非公開条件未達のフォトグラファーを検索結果で見る
- 未ログインで依頼を確定する

---

## 7. 正常系フロー

### フォトグラファー検索

1. ユーザーが検索画面を開き、フォトグラファータブを選択する
2. エリア、ジャンル、並び順を指定する
3. 条件に応じて結果が更新される
4. カードを押下して詳細ページへ遷移する

### 作品検索

1. ユーザーが作品タブを選択する
2. キーワード、ジャンル、エリア、並び順を指定する
3. 条件に応じて結果が更新される
4. 作品を押下してフォトグラファー詳細ページへ遷移する

### 詳細ページ閲覧

1. ユーザーがフォトグラファー詳細ページを開く
2. 表示名、自己紹介、活動エリア、対応ジャンル、公開ポートフォリオ、フォロワー数を確認する
3. ログイン済みであれば「フォローする」「依頼する」を利用できる

---

## 8. 検索条件と表示仕様

### フォトグラファー検索

| 項目     | 入力形式 | 備考                |
| -------- | -------- | ------------------- |
| エリア   | 単一選択 | 都道府県            |
| ジャンル | 複数選択 | セクション4参照     |
| 並び順   | 単一選択 | おすすめ順 / 新着順 |

**カード表示項目**

- アバター
- 表示名
- 活動都道府県
- 対応ジャンル最大3件
- 公開ポートフォリオ代表サムネイル最大3件
- フォロワー数

### 作品検索

| 項目       | 入力形式     | 備考                                 |
| ---------- | ------------ | ------------------------------------ |
| キーワード | テキスト入力 | タイトル、説明文、ハッシュタグを対象 |
| ジャンル   | 複数選択     | セクション4参照                      |
| エリア     | 単一選択     | 都道府県                             |
| 並び順     | 単一選択     | 新着順 / フォトグラファー名順        |

**作品表示項目**

- 正方形サムネイル
- ホバーまたはタップ時にタイトル、フォトグラファー名、ジャンルを表示

### ページング

- 1回の取得件数は24件
- 一覧は無限スクロール方式で追加読み込みする

### 並び順ルール

- おすすめ順は `エリア一致`、`ジャンル一致数`、`公開作品数`、`直近公開活動` をもとに算出する
- 新着順は直近の公開作品更新日時を基準にする

---

## 9. 例外・エラーケース

| ケース                                               | 表示・挙動                                   |
| ---------------------------------------------------- | -------------------------------------------- |
| 条件に一致するフォトグラファーがいない               | 条件見直しメッセージとリセット導線を表示する |
| 条件に一致する作品がない                             | 条件見直しメッセージとリセット導線を表示する |
| ネットワークエラー                                   | 再試行ボタンを表示する                       |
| 作品またはフォトグラファーが遷移直前に非公開になった | 閲覧不可メッセージを表示し、一覧へ戻す       |
| 未ログインで「依頼する」「フォローする」を押した     | ログイン画面へ遷移し、完了後に元ページへ戻す |

---

## 10. ビジネスルール

- 検索、詳細閲覧は未ログインでも利用できる
- 詳細ページではメールアドレス、電話番号、詳細住所は表示しない
- 自分自身のフォトグラファー詳細ページを開いた場合、「依頼する」は表示しない
- 停止済みユーザーや公開条件未達ユーザーは検索結果から除外する
- キーワード検索は大文字小文字、全角半角、ひらがなカタカナ差異を可能な範囲で吸収する
