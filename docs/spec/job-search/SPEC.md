# 機能仕様：案件検索（フォトグラファー向け）

## 1. 機能概要

### 機能名

案件検索

### 機能の目的

フォトグラファーが公募中の撮影依頼（案件）をエリア・ジャンル・予算などの条件で検索・閲覧し、提案したい案件を素早く見つけられるようにする。

### この機能で解決する課題

- フォトグラファーが自分のジャンルやエリアに合った案件を効率的に見つけられる
- 条件に合った案件に積極的に提案することで、受注機会を増やせる

---

## 2. 対象ユーザー

### 主な利用者

- 案件を探して提案を送りたいフォトグラファー（ログイン必須）

### 利用シーン

- 空き時間に受注できる案件がないか確認したいとき
- 得意なジャンルやよく活動するエリアで案件を絞り込みたいとき

---

## 3. 機能スコープ

### この機能に含むもの

- 公募中の案件一覧の閲覧
- エリア・ジャンル・予算・希望撮影日による絞り込み
- 案件詳細ページへの遷移
- 案件詳細ページからの提案送信（公募型依頼の提案送信フローに委譲）

### この機能に含まないもの

- 提案の送信（公募型依頼で対応）
- 指名型依頼の案件（指名型は該当フォトグラファーへの通知のみ）
- 公募の投稿・管理（依頼者側の機能）

---

## 4. ユーザーアクション

### ユーザーができること

- 公募中の案件一覧を閲覧する
- エリア・ジャンル・予算・希望撮影日で案件を絞り込む
- 案件カードをタップして詳細ページを確認する
- 詳細ページから「提案する」ボタンで提案送信フローへ進む

### ユーザーができないこと

- ログインせずに案件を閲覧する
- 自分が依頼者として投稿した公募を案件一覧に表示させる
- 確定済み・キャンセル済み・期限切れの案件を閲覧する

---

## 5. 正常系フロー

1. フォトグラファーが「案件を探す」画面を開く
2. エリア・ジャンル・予算・希望撮影日などの絞り込み条件を指定する（全条件任意・未指定で全件表示）
3. 条件変更のたびリアルタイムで検索結果が更新される
4. 案件カードをタップして詳細ページへ遷移する
5. 詳細ページで案件内容・依頼者プロフィールを確認し「提案する」ボタンをタップして提案送信フローへ進む

---

## 6. 検索条件・表示仕様

### 絞り込み条件

| 項目                 | 入力形式                 | 選択肢・備考                                                          |
| -------------------- | ------------------------ | --------------------------------------------------------------------- |
| エリア               | 単一選択ドロップダウン   | 都道府県（47都道府県）。依頼者が指定した撮影場所の都道府県と照合      |
| ジャンル・撮影シーン | 複数選択チェックボックス | 検索仕様のジャンル定義（セクション4）と共通                           |
| 予算                 | 単一選択ラジオ           | 下限なし（全件）/ ¥3,000以上 / ¥5,000以上 / ¥10,000以上 / ¥20,000以上 |
| 希望撮影日           | 日付範囲選択             | カレンダーで開始日〜終了日を指定                                      |

※ステータス「募集中」の案件のみ表示する（非表示フィルターとして常時適用）

**ソート順**

| 並び順               | 説明                     |
| -------------------- | ------------------------ |
| 新着順（デフォルト） | 公募投稿日が新しい順     |
| 予算が高い順         | 依頼者の提示予算が高い順 |
| 締切が近い順         | 希望撮影日が近い順       |

**案件カードに表示する情報**

- 撮影シーン（ジャンル）
- 希望撮影エリア（都道府県・市区町村）
- 希望日時（「◯月◯日（曜日）頃」など）
- 提示予算
- 補足・要望（先頭50文字程度のプレビュー）
- 投稿日時
- 現在の提案件数
- 提案済みバッジ（自分が既に提案している場合に表示）

---

## 7. 例外・エラーケース

| ケース                           | 表示・挙動                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------ |
| 絞り込み条件に合う案件がない     | 「条件に合う案件が見つかりませんでした」と表示し、条件リセットを促す           |
| 公募中の案件が0件（全体）        | 「現在公募中の案件はありません。しばらくしてから再度ご確認ください」と表示     |
| ネットワークエラー               | 「読み込みに失敗しました。再試行してください」と表示し、再試行ボタンを表示する |
| 既に提案済みの案件の詳細を開いた | 「提案する」ボタンを非活性にし「提案済みです」と表示する                       |

---

## 8. ビジネスルール

- 閲覧にはログインが必須（フォトグラファーロール）
- 「募集中」ステータスの公募のみ表示する（確定済み・キャンセル・期限切れは非表示）
- 自分が依頼者として投稿した公募は案件一覧に表示しない
- 既に自分が提案している案件には「提案済み」バッジを表示し、再提案は不可とする
- 案件詳細ページから依頼者のプロフィールページへ遷移できる（閲覧のみ）

---

## 9. 関連仕様

- 公募型依頼・提案比較・選択（案件の詳細表示・提案送信フロー）
- 通知（新着案件通知・提案結果通知）
- 検索（依頼者向け）（ジャンル定義を共用）
