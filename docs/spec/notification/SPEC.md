# 機能仕様：通知

## 1. 機能概要

### 機能名

通知

### 機能の目的

依頼・提案・メッセージなどの重要なイベント発生時に、ユーザーへプッシュ通知を送る。

### この機能で解決する課題

- ユーザーがアプリを開いていなくても重要なアクションを見逃さないようにする

---

## 2. 対象ユーザー

### 主な利用者

- 登録済みのすべてのユーザー（依頼者・フォトグラファー）

### 利用シーン

- 依頼・提案・承認・納品・メッセージなどのイベントが発生したとき

---

## 3. 機能スコープ

### この機能に含むもの

- プッシュ通知の送信
- アプリ内通知一覧の表示
- 通知の既読管理

### この機能に含まないもの

- メール通知
- SMS通知
- 通知種別ごとのON/OFF設定（MVP後の検討）

---

## 4. ユーザーアクション

### ユーザーができること

- 通知一覧を確認する
- 通知をタップして該当画面へ遷移する
- 通知を既読にする

### ユーザーができないこと

- 通知種別ごとのON/OFFを設定する（MVP対象外）

---

## 5. 通知イベント一覧

| イベント                       | 通知対象         | 通知内容                               |
| ------------------------------ | ---------------- | -------------------------------------- |
| 指名型依頼を受け取った         | フォトグラファー | 「新しい依頼が届きました」             |
| 指名型依頼が承認された         | 依頼者           | 「依頼が承認されました」               |
| 指名型依頼が拒否された         | 依頼者           | 「依頼が拒否されました」               |
| 公募に提案が届いた             | 依頼者           | 「新しい提案が届きました」             |
| 提案が選択された               | フォトグラファー | 「提案が採用されました」               |
| 提案が選択されなかった（落選） | フォトグラファー | 「別のフォトグラファーが選ばれました」 |
| 新規メッセージを受信した       | 相手ユーザー     | 「新しいメッセージが届きました」       |
| 写真が納品された               | 依頼者           | 「写真が納品されました」               |
| 納品が承認された               | フォトグラファー | 「納品が承認されました」               |
| やり直し要求が届いた           | フォトグラファー | 「やり直しの要求が届きました」         |

---

## 6. 例外・エラーケース

| ケース                     | 表示・挙動                           |
| -------------------------- | ------------------------------------ |
| プッシュ通知の許可が未設定 | アプリ内通知一覧のみに通知を表示する |
| 通知送信に失敗した         | リトライ処理を行う                   |

---

## 7. ビジネスルール

- 通知はイベント発生時にリアルタイムで送信する
- プッシュ通知の許可を設定していない場合でも、アプリ内通知一覧には表示する

---

## 8. 関連仕様

- 指名型依頼（依頼・承認・拒否の通知）
- 公募型依頼・提案比較・選択（提案・選択・落選の通知）
- チャット（新規メッセージの通知）
- 納品・納品確認（納品・承認・やり直しの通知）
