# 機能仕様：公募型依頼・提案比較・選択

## 1. 機能概要

### 機能名

公募型依頼・提案比較・選択

### 機能の目的

依頼者が撮影希望を公募として投稿し、複数のフォトグラファーから提案を受け取って比較・選択できるようにする。

### この機能で解決する課題

- 依頼者が複数のフォトグラファーの提案を比較することで、最適な価格・条件の撮影者を選べる
- フォトグラファーが自らアクティブに仕事を探せる機会を提供する

---

## 2. 対象ユーザー

### 主な利用者

- 依頼者（公募投稿・提案受取・選択を行う側）
- フォトグラファー（公募を閲覧・提案を送る側）

### 利用シーン

- 依頼者が「どのフォトグラファーにするか決めていないが、撮影してほしい」と思うとき
- フォトグラファーが公開された公募を見て、受注したいと思うとき

---

## 3. 機能スコープ

### この機能に含むもの

- 公募依頼の作成・投稿（撮影シーン・希望日時・場所・予算・補足事項）
- フォトグラファーによる公募閲覧・提案送信
- 依頼者による提案一覧の確認・比較
- 依頼者による提案の選択・承認

### この機能に含まないもの

- 指名型依頼（指名型依頼で対応）
- 選択後の決済処理（エスクロー決済で対応）
- チャット（チャットで対応）

---

## 4. ユーザーアクション

### ユーザーができること（依頼者）

- 公募依頼を投稿する
- 受け取った提案の一覧を確認・比較する
- 提案を選択して依頼を確定する
- 投稿した公募をキャンセルする（提案選択前）

### ユーザーができること（フォトグラファー）

- 公開中の公募一覧を閲覧する
- 公募に対して提案（料金・提案内容）を送信する
- 送信した提案を取り消す（依頼者が選択する前）

### ユーザーができないこと

- 依頼者が提案を選択した後に一方的にキャンセルする（キャンセルポリシーに従う）
- ログインせずに公募投稿・提案送信を行う

---

## 5. 正常系フロー

### 公募投稿（依頼者）

1. 依頼者が「公募する」ボタンをタップ
2. 撮影シーン・希望日時・場所・予算・補足事項を入力する
3. 入力内容を確認し「公募を投稿する」ボタンをタップ
4. 公募がフォトグラファーに公開される
5. 依頼のステータスが「募集中」となる

### 提案送信（フォトグラファー）

1. フォトグラファーが公募一覧から興味のある公募を選択する
2. 料金・提案内容・コメントを入力する
3. 「提案を送る」ボタンをタップ
4. 依頼者に提案通知が送信される（通知）

### 提案選択・依頼確定（依頼者）

1. 依頼者が受け取った提案一覧を確認する
2. 各提案の料金・フォトグラファーのプロフィール・ポートフォリオを比較する
3. 希望の提案を選択し「この提案で依頼する」ボタンをタップ
4. 依頼が確定し、エスクロー決済へ進む（エスクロー決済）
5. 選択されなかったフォトグラファーへ落選通知が送信される（通知）

---

## 6. 例外・エラーケース

| ケース                                               | 表示・挙動                                         |
| ---------------------------------------------------- | -------------------------------------------------- |
| 同一フォトグラファーが同一公募に二重提案しようとした | 「すでに提案を送信しています」と表示し送信不可     |
| 提案が0件のまま公募の有効期限が過ぎた                | 依頼者に通知し、公募を「期限切れ」ステータスに更新 |
| 依頼者が提案選択前に公募をキャンセルした             | 提案済みフォトグラファー全員にキャンセル通知を送信 |

---

## 7. ビジネスルール

- 依頼者・フォトグラファーともにログイン必須
- 1つの公募に対して複数のフォトグラファーが提案できる
- 依頼者が提案を選択した時点で、他の提案は自動的に辞退扱いとなる
- 選択後のキャンセルはキャンセルポリシーに従う

---

## 8. 関連仕様

- フォトグラファー検索・閲覧（フォトグラファーのプロフィール・ポートフォリオ確認）
- チャット（提案後のコミュニケーション）
- エスクロー決済（提案選択後の決済処理）
- 通知（提案送信・選択・落選の通知）
