# 機能仕様：ポートフォリオ管理

## 1. 機能概要

### 機能名

ポートフォリオ管理

### 機能の目的

フォトグラファーが自分の作品写真をアップロード・公開し、依頼者に撮影スタイルやスキルをアピールできるようにする。

### この機能で解決する課題

- フォトグラファーが技術を活かせる場を提供し、副収入につなげられる
- 依頼者がフォトグラファーの撮影スタイルを事前に確認でき、ミスマッチを防げる

---

## 2. 対象ユーザー

### 主な利用者

- フォトグラファー（ポートフォリオを管理・公開する側）

### 利用シーン

- フォトグラファーが新しい作品写真を追加したいとき
- フォトグラファーが既存の作品を削除・整理したいとき

---

## 3. 機能スコープ

### この機能に含むもの

- 作品写真のアップロード
- 作品写真のタイトル・説明・ジャンルの設定
- 作品写真の削除
- 公開・非公開の切り替え

### この機能に含まないもの

- 動画のアップロード
- ポートフォリオの閲覧（フォトグラファー検索・閲覧で対応）
- 写真販売（フェーズ2）

---

## 4. ユーザーアクション

### ユーザーができること

- 作品写真をアップロードする
- 作品にタイトル・説明・ジャンルを設定する
- 作品を公開・非公開に切り替える
- 作品を削除する
- アップロード済み作品の一覧を確認する

### ユーザーができないこと

- 他のフォトグラファーの作品を管理する
- 動画をアップロードする

---

## 5. 正常系フロー

### 作品アップロード

1. フォトグラファーがポートフォリオ管理画面を開く
2. 「作品を追加」ボタンをタップ
3. 写真ファイルを選択する
4. タイトル・説明・ジャンルを入力する（任意項目あり）
5. 「公開する」または「下書き保存」を選択して保存
6. アップロード完了後、作品一覧に表示される

### 作品削除

1. フォトグラファーが削除したい作品を選択する
2. 「削除する」ボタンをタップ
3. 確認ダイアログで「削除」を選択
4. 作品一覧から削除される

---

## 6. 例外・エラーケース

| ケース                               | 表示・挙動                                             |
| ------------------------------------ | ------------------------------------------------------ |
| アップロードファイルがサイズ上限超過 | 「ファイルサイズが上限を超えています」と表示           |
| 非対応フォーマットのファイル         | 「JPEG・PNG・WEBPのみ対応しています」と表示            |
| アップロード中にネットワークエラー   | エラーメッセージを表示し、再試行を促す                 |
| 作品数が上限に達している             | 「アップロード可能な作品数の上限に達しています」と表示 |

---

## 7. ビジネスルール

- ポートフォリオはフォトグラファーのみ管理できる
- 公開された作品は、ログイン不要で閲覧できる（フォトグラファー検索・閲覧）
- 非公開作品は本人のみ閲覧できる

---

## 8. 関連仕様

- フォトグラファー検索・閲覧（ポートフォリオが検索・詳細ページで表示される）
