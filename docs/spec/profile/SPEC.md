# 機能仕様：プロフィール管理

## 1. 機能概要

### 機能名

プロフィール管理

### 機能の目的

ユーザーが氏名・アバター・自己紹介などの基本情報を登録・編集できるようにする。

### この機能で解決する課題

- 依頼者・フォトグラファー双方が相手の素性を確認でき、安心して取引できる

---

## 2. 対象ユーザー

### 主な利用者

- 登録済みのすべてのユーザー（依頼者・フォトグラファー共通）

### 利用シーン

- 新規登録直後にプロフィールを初期設定するとき
- 氏名・アバター・自己紹介を変更したいとき

---

## 3. 機能スコープ

### この機能に含むもの

- 氏名の設定・変更
- アバター画像のアップロード・変更
- 自己紹介文の設定・変更

### この機能に含まないもの

- ポートフォリオ写真の管理（ポートフォリオ管理で対応）
- スケジュール設定（スケジュール管理で対応）
- 銀行口座情報・支払い情報の管理

---

## 4. ユーザーアクション

### ユーザーができること

- 氏名を入力・変更する
- アバター画像をアップロード・変更する
- 自己紹介文を入力・変更する
- プロフィールを保存する

### ユーザーができないこと

- メールアドレスの変更（Googleアカウントに紐づくため変更不可）
- 他のユーザーのプロフィールを編集する

---

## 5. 正常系フロー

1. ユーザーがプロフィール編集画面を開く
2. 氏名・自己紹介を入力する
3. 必要に応じてアバター画像をアップロードする
4. 「保存する」ボタンをタップ
5. バリデーション成功後、プロフィール情報を保存
6. 保存完了のフィードバックを表示する

---

## 6. 例外・エラーケース

| ケース                                 | 表示・挙動                                           |
| -------------------------------------- | ---------------------------------------------------- |
| 氏名が未入力                           | 「氏名を入力してください」と表示し、保存不可         |
| 自己紹介文が文字数上限を超過           | 入力中にリアルタイムで文字数を表示し、上限超過を通知 |
| アバター画像がファイルサイズ上限を超過 | 「ファイルサイズが上限を超えています」と表示         |
| アバター画像が非対応フォーマット       | 「JPEG・PNG・WEBPのみ対応しています」と表示          |

---

## 7. ビジネスルール

- 氏名は必須項目
- アバター画像は任意。未設定の場合はデフォルトアバターを表示
- 依頼者・フォトグラファーで共通のプロフィールを使用する（役割別のプロフィールは持たない）

---

## 8. 関連仕様

- 新規登録・ログイン（登録後にプロフィール設定へ遷移）
- フォトグラファー検索・閲覧（プロフィールが検索結果・詳細ページに表示される）
