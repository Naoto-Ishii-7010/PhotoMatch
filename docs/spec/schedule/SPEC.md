# 機能仕様：スケジュール管理

## 1. 機能概要

### 機能名

スケジュール管理

### 機能の目的

フォトグラファーが撮影を受け付けられる日時を登録・管理できるようにする。

### この機能で解決する課題

- 依頼者がフォトグラファーの空き状況を確認してから依頼できるため、日程調整の手間を削減できる

---

## 2. 対象ユーザー

### 主な利用者

- フォトグラファー（空き日時を設定・管理する側）

### 利用シーン

- フォトグラファーが受付可能な日時を事前に登録するとき
- 既に登録した空き日時を変更・削除するとき

---

## 3. 機能スコープ

### この機能に含むもの

- 受付可能な日時（スロット）の登録
- 登録した日時の変更・削除
- カレンダー形式での空き日時の表示

### この機能に含まないもの

- 依頼者側からのスケジュール閲覧（フォトグラファー検索・閲覧、指名型依頼で対応）
- 外部カレンダーとの連携

---

## 4. ユーザーアクション

### ユーザーができること

- 受付可能な日時を登録する
- 登録した日時を変更・削除する
- カレンダーで自分の空き状況を確認する

### ユーザーができないこと

- 他のフォトグラファーのスケジュールを編集する
- 外部カレンダーと同期する

---

## 5. 正常系フロー

### 空き日時の登録

1. フォトグラファーがスケジュール管理画面を開く
2. カレンダーから日付を選択する
3. 開始時間・終了時間を指定する
4. 「登録する」ボタンをタップ
5. 選択した日時がスケジュールに追加される

### 空き日時の削除

1. フォトグラファーがスケジュール管理画面を開く
2. 削除したいスロットをタップする
3. 「削除する」を選択する
4. スケジュールから該当の日時が削除される

---

## 6. 例外・エラーケース

| ケース                                     | 表示・挙動                                       |
| ------------------------------------------ | ------------------------------------------------ |
| 過去の日時を登録しようとした               | 「過去の日時は登録できません」と表示             |
| 既存の登録と重複する日時を登録しようとした | 「他の予定と重複しています」と表示               |
| 依頼確定済みのスロットを削除しようとした   | 「確定済みの依頼があるため削除できません」と表示 |

---

## 7. ビジネスルール

- 依頼が確定した日時はスロットが自動的にブロックされ、重複した依頼を受け付けない
- 過去の日時は登録・変更不可

---

## 8. 関連仕様

- フォトグラファー検索・閲覧（空き日時が依頼者に表示される）
- 指名型依頼（依頼確定時に該当スロットをブロック）
- 公募型依頼（依頼確定時に該当スロットをブロック）
