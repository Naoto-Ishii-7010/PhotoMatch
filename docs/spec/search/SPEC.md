# 機能仕様：検索（依頼者向け）

## 1. 機能概要

### 機能名

検索（フォトグラファー検索・ポートフォリオ検索）

### 機能の目的

依頼者がフォトグラファーや作品写真を検索・閲覧し、撮影を依頼したいフォトグラファーを見つけられるようにする。

### この機能で解決する課題

- 依頼者が自分のニーズに合ったフォトグラファーを効率的に見つけられる
- 作品写真から先に気に入ったスタイルを探し、そのフォトグラファーを発見できる
- 検索から依頼へのスムーズな動線を提供する

---

## 2. 対象ユーザー

### 主な利用者

- 撮影を依頼したい依頼者（ログイン不要）

### 利用シーン

- 撮影を依頼するフォトグラファーを探すとき
- 気になる作品スタイルのフォトグラファーを見つけたいとき

---

## 3. 機能スコープ

### この機能に含むもの

**フォトグラファー検索**

- エリア・ジャンル・評価によるフォトグラファーの絞り込み検索
- フォトグラファー一覧のカード表示
- フォトグラファー詳細ページへの遷移

**ポートフォリオ検索**

- キーワード・ジャンル・エリアによる公開作品の絞り込み検索
- 作品のグリッド表示
- 作品からフォトグラファー詳細ページへの遷移

### この機能に含まないもの

- 依頼の送信（指名型依頼で対応）
- フォトグラファーへのレビュー投稿（フェーズ2）
- 案件検索（フォトグラファー向け機能として別仕様で対応）

---

## 4. ジャンル定義

本サービス共通のジャンル（撮影シーン）一覧。フォトグラファー検索・ポートフォリオ検索・案件検索で共通して使用する。

| ジャンル             | 主な対象・シーン                     |
| -------------------- | ------------------------------------ |
| ポートレート         | 個人・プロフィール写真               |
| ファミリー・記念日   | 家族写真・誕生日・記念日             |
| ウェディング・婚礼   | 結婚式・前撮り・フォトウェディング   |
| 七五三・節目行事     | 七五三・入学・卒業・成人式           |
| スポーツ・アクション | スポーツ・アクティビティ・モデル撮影 |
| ペット               | 動物・ペット写真                     |
| 風景・自然           | 風景・自然・旅行写真                 |
| 建築・インテリア     | 建物・内装・空間写真                 |
| 料理・商品           | 食べ物・商品・物撮り                 |
| イベント・パーティー | 各種イベント・パーティー・発表会     |
| その他               | 上記に当てはまらない撮影             |

---

## 5. ユーザーアクション

### ユーザーができること

- 「フォトグラファー検索」でエリア・ジャンル・評価を指定してフォトグラファーを探す
- 「ポートフォリオ検索」でキーワード・ジャンル・エリアを指定して作品を探す
- 検索結果のカードや作品画像からフォトグラファー詳細ページに遷移する
- フォトグラファー詳細ページでプロフィール・ポートフォリオを閲覧する

### ユーザーができないこと

- ログインせずに依頼を送信する（閲覧のみ可能）
- 非公開設定の作品を閲覧する

---

## 5. 正常系フロー

### フォトグラファー検索

1. ユーザーが検索画面を開き「フォトグラファーを探す」タブを選択する
2. エリア・ジャンル・評価などの絞り込み条件を指定する（全条件任意・未指定で全件表示）
3. 条件変更のたびリアルタイムで検索結果が更新される
4. フォトグラファーカードをタップしてフォトグラファー詳細ページへ遷移する

### ポートフォリオ検索

1. ユーザーが検索画面を開き「作品を探す」タブを選択する
2. キーワード・ジャンル・エリアなどの絞り込み条件を指定する（全条件任意・未指定で全件表示）
3. 条件変更のたびリアルタイムで検索結果が更新される
4. 作品画像をタップしてフォトグラファー詳細ページへ遷移する

### フォトグラファー詳細閲覧

1. ユーザーがフォトグラファーの詳細ページを開く
2. プロフィール・自己紹介・公開ポートフォリオ写真が表示される
3. 「依頼する」ボタンをタップして指名型依頼へ進む（ログイン必須）

---

## 6. 検索条件・表示仕様

### フォトグラファー検索の絞り込み条件

| 項目     | 入力形式                 | 選択肢・備考                                                       |
| -------- | ------------------------ | ------------------------------------------------------------------ |
| エリア   | 単一選択ドロップダウン   | 都道府県（47都道府県）。フォトグラファーの活動エリアと照合         |
| ジャンル | 複数選択チェックボックス | セクション4のジャンル定義参照                                      |
| 評価     | 単一選択ラジオ           | すべて / 3.0以上 / 4.0以上 / 4.5以上（レビュー機能実装後に有効化） |

**ソート順**

| 並び順                   | 説明                                           |
| ------------------------ | ---------------------------------------------- |
| おすすめ順（デフォルト） | 評価スコアとポートフォリオ投稿数の複合スコア順 |
| 評価が高い順             | 平均評価スコアの高い順                         |
| 新着順                   | 直近のポートフォリオ投稿が新しい順             |

**フォトグラファーカードに表示する情報**

- アバター画像
- 表示名
- 活動エリア（都道府県）
- 対応ジャンル（最大3件表示、超過分は「他◯件」）
- 平均評価（星表示 + 数値）・レビュー件数
- ポートフォリオ代表画像（最大3枚のサムネイル）

### ポートフォリオ検索の絞り込み条件

| 項目       | 入力形式                 | 選択肢・備考                                               |
| ---------- | ------------------------ | ---------------------------------------------------------- |
| キーワード | テキスト入力             | 作品タイトル・説明文・ハッシュタグを全文検索               |
| ジャンル   | 複数選択チェックボックス | セクション4のジャンル定義参照                              |
| エリア     | 単一選択ドロップダウン   | 都道府県（47都道府県）。フォトグラファーの活動エリアと照合 |

**ソート順**

| 並び順                 | 説明                               |
| ---------------------- | ---------------------------------- |
| 新着順（デフォルト）   | 作品投稿日が新しい順               |
| フォトグラファー評価順 | フォトグラファーの平均評価が高い順 |

**作品グリッドに表示する情報**

- 作品画像（正方形サムネイル形式でグリッド表示）
- タップ時：作品タイトル・フォトグラファー名・ジャンルをオーバーレイ表示

---

## 7. 例外・エラーケース

| ケース                                     | 表示・挙動                                                                       |
| ------------------------------------------ | -------------------------------------------------------------------------------- |
| 検索条件に該当するフォトグラファーがいない | 「条件に合うフォトグラファーが見つかりませんでした」と表示し、条件リセットを促す |
| 検索条件に該当する作品がない               | 「条件に合う作品が見つかりませんでした」と表示し、条件リセットを促す             |
| ネットワークエラー                         | 「読み込みに失敗しました。再試行してください」と表示し、再試行ボタンを表示する   |

---

## 8. ビジネスルール

- 検索・閲覧はログイン不要
- ポートフォリオの公開設定が「公開」の作品のみ表示する
- 退会・停止済みユーザーのフォトグラファーは検索結果に表示しない
- 評価フィルターは、レビュー機能が未実装のフェーズ1では非表示とする（フェーズ2で有効化）
- ポートフォリオ検索でキーワード未指定の場合、全公開作品を最新順で表示する
