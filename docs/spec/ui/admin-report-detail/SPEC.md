# 画面仕様：管理通報詳細

## 1. 画面概要

### 画面名

管理通報詳細

### 想定ルート

`/admin/reports/[reportId]`

### 画面の目的

管理者が通報対象、関連ユーザー、案件、メッセージを確認し、対応結果を記録できるようにする。

---

## 2. 対象ユーザー

- 管理者

---

## 3. 主な遷移

| 流入元           | 条件       |
| ---------------- | ---------- |
| `/admin/reports` | 通報行押下 |

| UI 要素                                      | 遷移先                  | 備考         |
| -------------------------------------------- | ----------------------- | ------------ |
| `問題なし`、`警告`、`停止`、`案件キャンセル` | 同画面                  | 対応記録保存 |
| 関連ユーザー                                 | `/admin/users/[userId]` | ドリルダウン |

---

## 4. レイアウトと UI 要素

- 通報基本情報
- 対象種別、対象 ID、理由、詳細コメント
- 関連ユーザー情報
- 関連案件、メッセージ参照
- 対応結果選択
- 対応コメント入力
- 監査ログ表示

---

## 5. ユーザー操作

- 通報内容を確認する
- 対応結果を記録する
- 必要に応じて停止や案件キャンセルへ連携する

---

## 6. 状態・バリデーション

| ケース       | 表示                       |
| ------------ | -------------------------- |
| 対象削除済み | 参照不能表示、履歴のみ表示 |
| 権限なし     | 403 相当                   |
| 保存失敗     | 再試行導線                 |
