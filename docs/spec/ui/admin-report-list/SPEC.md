# 画面仕様：管理通報一覧

## 1. 画面概要

### 画面名

管理通報一覧

### 想定ルート

`/admin/reports`

### 画面の目的

管理者が未対応通報を優先的に確認し、対象詳細へ遷移できるようにする。

---

## 2. 対象ユーザー

- 管理者
- 運営スタッフ

---

## 3. 主な遷移

| 流入元             | 条件           |
| ------------------ | -------------- |
| 管理ナビゲーション | 管理者権限のみ |

| UI 要素 | 遷移先                      | 備考   |
| ------- | --------------------------- | ------ |
| 通報行  | `/admin/reports/[reportId]` | 詳細へ |

---

## 4. レイアウトと UI 要素

- 状態フィルタ
- 対象種別フィルタ
- 未対応先頭の一覧テーブル
- 各行に通報理由、対象種別、対象 ID、通報者、発生日時、対応状態

---

## 5. ユーザー操作

- 未対応案件を確認する
- 条件絞り込み
- 詳細へ遷移

---

## 6. 状態・バリデーション

| ケース   | 表示       |
| -------- | ---------- |
| 該当なし | 空状態     |
| 権限なし | 403 相当   |
| 取得失敗 | 再試行導線 |
