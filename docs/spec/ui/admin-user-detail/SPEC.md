# 画面仕様：管理ユーザー詳細

## 1. 画面概要

### 画面名

管理ユーザー詳細

### 想定ルート

`/admin/users/[userId]`

### 画面の目的

管理者が対象ユーザーのプロフィール、ポートフォリオ、案件履歴、通報履歴、チャット履歴を確認し、停止や再開などの操作を行えるようにする。

---

## 2. 対象ユーザー

- 管理者

---

## 3. 主な遷移

| 流入元         | 条件       |
| -------------- | ---------- |
| `/admin/users` | 対象行押下 |

| UI 要素    | 遷移先       | 備考           |
| ---------- | ------------ | -------------- |
| `停止する` | 同画面       | 理由入力必須   |
| `再開する` | 同画面       | 状態更新       |
| 関連案件   | 該当管理詳細 | 実装時導線調整 |

---

## 4. レイアウトと UI 要素

- 基本情報
- 公開プロフィール、公開作品要約
- 案件履歴
- 通報履歴
- チャット履歴参照
- 監査ログ
- 停止、再開アクション

---

## 5. ユーザー操作

- 履歴を横断参照する
- 停止、再開する
- 必要に応じて関連案件を確認する

---

## 6. 状態・バリデーション

| ケース       | 表示                       |
| ------------ | -------------------------- |
| 既に停止済み | 停止処理不可、現状態表示   |
| 一部更新失敗 | 警告表示とリトライ対象明示 |
| 権限なし     | 403 相当                   |
