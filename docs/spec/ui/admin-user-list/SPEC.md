# 画面仕様：管理ユーザー一覧

## 1. 画面概要

### 画面名

管理ユーザー一覧

### 想定ルート

`/admin/users`

### 画面の目的

管理者がユーザーを検索し、停止状態や通報状況を確認しながら詳細画面へドリルダウンできるようにする。

---

## 2. 対象ユーザー

- 管理者
- 運営スタッフ

---

## 3. 主な遷移

| 流入元             | 条件           |
| ------------------ | -------------- |
| 管理ナビゲーション | 管理者権限のみ |

| UI 要素    | 遷移先                  | 備考   |
| ---------- | ----------------------- | ------ |
| ユーザー行 | `/admin/users/[userId]` | 詳細へ |

---

## 4. レイアウトと UI 要素

- 表示名、メール、状態での検索
- 状態フィルタ
- 一覧テーブル
- 各行に表示名、メールアドレス、状態、通報件数、最終利用日時

---

## 5. ユーザー操作

- 条件検索
- 状態確認
- 詳細画面への遷移

---

## 6. 状態・バリデーション

| ケース   | 表示       |
| -------- | ---------- |
| 該当なし | 空状態表示 |
| 権限なし | 403 相当   |
| 検索失敗 | 再試行導線 |
