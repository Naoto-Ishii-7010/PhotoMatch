# 画面仕様：ログイン

## 1. 画面概要

### 画面名

ログイン

### 想定ルート

`/auth/login`

### 画面の目的

既存ユーザーに Google OAuth による再ログインを行わせ、元の画面またはトップ画面へ復帰させる。

### 実装ステータス

現時点では画面未実装。Supabase Auth 導入時の画面案として扱う。

---

## 2. 対象ユーザー

- 既存会員
- セッション切れユーザー
- 認証必須画面へ到達した未ログインユーザー

---

## 3. 主な遷移

| 流入元     | 条件                             |
| ---------- | -------------------------------- |
| LP         | ヘッダー `ログイン`              |
| 各保護画面 | 未ログイン、またはセッション失効 |

| UI 要素                 | 遷移先                | 備考         |
| ----------------------- | --------------------- | ------------ |
| `Google でログインする` | Google OAuth          | 認証開始     |
| `新規登録はこちら`      | `/auth/register`      | 新規会員向け |
| ログイン完了後          | 遷移元 URL または `/` | 優先順位あり |

---

## 4. レイアウトと UI 要素

- サービスロゴ
- 見出しと説明文
- `Google でログインする` ボタン
- セッション切れ時の補足メッセージ
- 新規登録導線

---

## 5. ユーザー操作

- Google 認証を開始する
- ログイン成功後に元画面へ戻る
- 新規ユーザーは登録画面へ切り替える

---

## 6. 状態・バリデーション

| ケース                | 表示                             |
| --------------------- | -------------------------------- |
| Google 認証キャンセル | 画面に戻して再試行可能           |
| 停止済みアカウント    | ログイン拒否、問い合わせ導線表示 |
| セッション失効経由    | `再ログインが必要です` を表示    |
| サーバーエラー        | エラー文言と再試行導線表示       |
