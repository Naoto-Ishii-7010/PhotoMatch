# 画面仕様：新規登録

## 1. 画面概要

### 画面名

新規登録

### 想定ルート

`/auth/register`

### 画面の目的

未登録ユーザーに Google OAuth による会員登録を開始させ、初回同意取得後にプロフィール初期設定へ進める。

---

## 2. 対象ユーザー

- 初めて `PhotoMatch` を利用する未ログインユーザー
- LP や認証必須画面から登録導線へ遷移したユーザー

---

## 3. 主な遷移

| 流入元       | 条件                         |
| ------------ | ---------------------------- |
| LP           | `無料ではじめる`、役割別 CTA |
| 認証必須画面 | 未ログイン時のリダイレクト   |

| UI 要素              | 遷移先            | 備考                 |
| -------------------- | ----------------- | -------------------- |
| `Google で登録する`  | Google OAuth      | 認証開始             |
| `ログインはこちら`   | `/auth/login`     | 既存会員向け         |
| 利用規約             | 規約ページ        | 別タブ想定           |
| プライバシーポリシー | ポリシーページ    | 別タブ想定           |
| 登録完了後           | `/mypage/profile` | 初期設定モードで表示 |

---

## 4. レイアウトと UI 要素

- サービスロゴ
- 見出しと補足文
- 役割プリセット表示
  `role=requester` または `role=photographer` がある場合は初期利用意図を表示する
- `Google で登録する` ボタン
- 利用規約、プライバシーポリシーへの同意チェックボックス
- ログイン導線

---

## 5. ユーザー操作

- 同意チェック後に登録を開始できる
- Google 認証成功後、初回登録ならアカウントを作成する
- 既存アカウントだった場合は新規作成せずログインとして扱う

---

## 6. 状態・バリデーション

| ケース                | 表示                                 |
| --------------------- | ------------------------------------ |
| 同意未チェック        | OAuth 開始不可、エラーメッセージ表示 |
| Google 認証キャンセル | 画面に戻し再試行可能                 |
| 停止済みアカウント    | ログイン拒否と問い合わせ導線表示     |
| サーバーエラー        | 汎用エラーと再試行導線表示           |
