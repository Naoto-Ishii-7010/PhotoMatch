# 画面仕様：チャット一覧

## 1. 画面概要

### 画面名

チャット一覧

### 想定ルート

`/chats`

### 画面の目的

進行中または履歴保持中の案件チャットを一覧表示し、未読や案件状態を確認しながら対象ルームへ入れるようにする。

---

## 2. 対象ユーザー

- マッチ成立済み案件の当事者

---

## 3. 主な遷移

| 流入元         | 条件                 |
| -------------- | -------------------- |
| ナビゲーション | ログイン済み         |
| 通知           | 新着メッセージ受信時 |

| UI 要素    | 遷移先            | 備考         |
| ---------- | ----------------- | ------------ |
| チャット行 | `/chats/[chatId]` | ルーム詳細へ |

---

## 4. レイアウトと UI 要素

- 未読件数サマリー
- チャット行一覧
- 各行に相手名、案件ジャンル、最新メッセージ、未読件数、案件状態

---

## 5. ユーザー操作

- 一覧からルームを選択する
- 未読ルームを優先確認する

---

## 6. 状態・バリデーション

| ケース               | 表示                           |
| -------------------- | ------------------------------ |
| 0件                  | 空状態と案件導線               |
| 完了、キャンセル済み | 履歴として表示、状態バッジ付与 |
| ネットワークエラー   | 再試行導線                     |
