# 画面仕様：チャットルーム

## 1. 画面概要

### 画面名

チャットルーム

### 想定ルート

`/chats/[chatId]`

### 画面の目的

マッチ成立後の当事者が撮影条件を安全に調整し、案件完了までの状態変化を確認できるようにする。

---

## 2. 対象ユーザー

- 指名依頼または公募採用後の依頼者
- 対応するフォトグラファー

---

## 3. 主な遷移

| 流入元             | 条件                           |
| ------------------ | ------------------------------ |
| 指名依頼詳細       | マッチ成立後                   |
| 公募詳細、提案一覧 | 採用後                         |
| 通知               | 新着メッセージ、完了待ち、完了 |

| UI 要素      | 遷移先  | 備考         |
| ------------ | ------- | ------------ |
| `完了に進む` | 同画面  | 状態更新     |
| `通報する`   | 通報 UI | 実装方式未定 |

---

## 4. レイアウトと UI 要素

- ヘッダー
  相手名、案件ジャンル、状態
- システムメッセージ
- メッセージ一覧
- 入力欄、送信ボタン
- 完了導線

---

## 5. ユーザー操作

- メッセージ送信
- 既読確認
- 完了操作
- 不適切内容の通報

---

## 6. 状態・バリデーション

| ケース               | 表示         |
| -------------------- | ------------ |
| マッチ成立前アクセス | 閲覧不可     |
| 空メッセージ         | 送信不可     |
| 2000文字超過         | 送信不可     |
| 完了、キャンセル済み | 入力欄非表示 |
| 送信失敗             | 再送導線     |
