# 画面仕様：指名依頼詳細

## 1. 画面概要

### 画面名

指名依頼詳細

### 想定ルート

`/direct-requests/[requestId]`

### 画面の目的

送信済み指名依頼の状態、依頼条件、相手のアクション結果を確認し、必要に応じて承認、辞退、キャンセル、チャット遷移を行えるようにする。

---

## 2. 対象ユーザー

- 依頼者
- 依頼を受けたフォトグラファー

---

## 3. 主な遷移

| 流入元             | 条件                           |
| ------------------ | ------------------------------ |
| 通知               | 新規依頼、承認、辞退、期限切れ |
| マイページ案件一覧 | 実装時導線想定                 |

| UI 要素          | 遷移先            | 備考                 |
| ---------------- | ----------------- | -------------------- |
| `承認する`       | 同画面            | フォトグラファーのみ |
| `辞退する`       | 同画面            | フォトグラファーのみ |
| `キャンセルする` | 同画面            | 状態条件あり         |
| `チャットへ進む` | `/chats/[chatId]` | マッチ成立後         |

---

## 4. レイアウトと UI 要素

- ステータスバッジ
- 相手ユーザー要約
- 依頼条件一覧
- 期限表示
- 依頼者 / フォトグラファー別アクション
- 履歴、キャンセル理由、期限切れ理由表示

---

## 5. ユーザー操作

- 依頼者は状態確認、キャンセル、完了操作を行う
- フォトグラファーは承認、辞退、キャンセル、完了操作を行う
- マッチ成立後はチャット導線が主アクションになる

---

## 6. 状態・バリデーション

| ケース            | 表示                             |
| ----------------- | -------------------------------- |
| `募集中`          | 承認、辞退、依頼者キャンセル可能 |
| `マッチ成立` 以降 | チャット CTA を表示              |
| 承認期限切れ      | `キャンセル` と理由区分表示      |
| 権限外アクセス    | 閲覧不可                         |
