# 画面仕様：指名依頼作成

## 1. 画面概要

### 画面名

指名依頼作成

### 想定ルート

`/direct-requests/new`

### 画面の目的

依頼者が対象フォトグラファーへ撮影条件を入力し、指名依頼を送信できるようにする。

---

## 2. 対象ユーザー

- ログイン済み依頼者

---

## 3. 主な遷移

| 流入元               | 条件            |
| -------------------- | --------------- |
| フォトグラファー詳細 | `依頼する` 押下 |

| UI 要素      | 遷移先                            | 備考         |
| ------------ | --------------------------------- | ------------ |
| `送信する`   | `/direct-requests/[requestId]`    | 送信後詳細へ |
| `キャンセル` | `/photographers/[photographerId]` | 送信前離脱   |

---

## 4. レイアウトと UI 要素

- 依頼先フォトグラファー要約
- 撮影ジャンル
- 希望撮影日
- 撮影エリア
- 予算
- 補足事項
- `送信する` ボタン

---

## 5. ユーザー操作

- 必須項目を入力して送信する
- 下書きなしで即時送信する
- 既存の承認待ち依頼がある場合は新規送信できない

---

## 6. 状態・バリデーション

| ケース                 | 表示               |
| ---------------------- | ------------------ |
| 未ログイン             | ログインへ誘導     |
| 同一相手に承認待ちあり | 既存依頼詳細へ誘導 |
| 予算未入力、0円以下    | 保存不可           |
| 補足事項1000文字超過   | 保存不可           |
| 相手が停止、退会       | 送信不可           |
