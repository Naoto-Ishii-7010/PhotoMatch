# 画面仕様：フォロー一覧

## 1. 画面概要

### 画面名

フォロー一覧

### 想定ルート

`/mypage/follows`

### 画面の目的

保存したフォトグラファーを最新フォロー順で一覧表示し、再比較や再依頼へつなげる。

---

## 2. 対象ユーザー

- ログイン済みユーザー

---

## 3. 主な遷移

| 流入元     | 条件     |
| ---------- | -------- |
| マイページ | 通常導線 |

| UI 要素                | 遷移先                            | 備考           |
| ---------------------- | --------------------------------- | -------------- |
| フォトグラファーカード | `/photographers/[photographerId]` | 詳細へ         |
| `フォロー中`           | 同画面                            | 解除アクション |

---

## 4. レイアウトと UI 要素

- 一覧件数表示
- 最新フォロー順のカード一覧
- 各カードにアバター、表示名、都道府県、対応ジャンル最大3件
- 空状態 CTA

---

## 5. ユーザー操作

- 一覧閲覧
- フォロー解除
- 詳細ページへの遷移

---

## 6. 状態・バリデーション

| ケース       | 表示             |
| ------------ | ---------------- |
| 0件          | 空状態と検索導線 |
| 通信失敗     | 再試行導線       |
| 停止済み対象 | 一覧から自動除外 |
