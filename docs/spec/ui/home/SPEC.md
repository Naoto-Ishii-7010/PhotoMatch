# 画面仕様：ルートホーム（暫定）

## 1. 画面概要

### 画面名

ルートホーム（暫定プレースホルダー）

### ルート

`/`

### 画面の目的

Next.js 初期テンプレートをそのまま表示する暫定画面であり、現時点ではサービス固有の導線や業務機能は持たない。

---

## 2. 対象ユーザー

### 主な閲覧者

- 直接 `/` にアクセスした未ログインユーザー
- 開発者、検証担当者

### 利用シーン

- 開発初期の疎通確認
- デプロイ直後のトップルート確認

---

## 3. 画面遷移

### 流入

- ブラウザから `/` へ直接アクセスする

### 遷移先

| UI 要素                | 遷移先                  | 備考     |
| ---------------------- | ----------------------- | -------- |
| `Templates` リンク     | Vercel テンプレート一覧 | 新規タブ |
| `Learning` リンク      | Next.js Learn           | 新規タブ |
| `Deploy Now` ボタン    | Vercel New              | 新規タブ |
| `Documentation` ボタン | Next.js Docs            | 新規タブ |

---

## 4. レイアウト構成

### 全体構成

- 背景は薄いグレー
- 中央に白いコンテンツカラムを1枚配置する
- 上から `Next.js ロゴ`、説明文、CTA ボタン群の順で縦配置する

### レイアウトルール

- 画面全体を縦横中央寄せで表示する
- コンテンツ最大幅は `max-w-3xl`
- モバイルでは中央揃え、`sm` 以上では左揃えへ切り替える

---

## 5. UI 要素

| エリア       | 内容                                      | 挙動             |
| ------------ | ----------------------------------------- | ---------------- |
| ロゴ         | `next.svg` を表示                         | 操作なし         |
| メインコピー | `To get started, edit the page.tsx file.` | 操作なし         |
| 補足文       | テンプレート、学習導線の説明              | 文中リンクあり   |
| 主 CTA       | `Deploy Now`                              | 外部サイトへ遷移 |
| 副 CTA       | `Documentation`                           | 外部サイトへ遷移 |

---

## 6. 表示状態とインタラクション

- 入力フォーム、モーダル、タブ、アコーディオンはない
- ローディング状態、空状態、エラー状態の専用 UI は持たない
- すべて静的表示であり、サービスデータは参照しない

---

## 7. 画面上の課題

- `PhotoMatch` のブランド導線になっていない
- `/lp` への遷移導線が存在しない
- サービス利用者向けトップ画面としては未完成
