# 画面仕様：案件検索

## 1. 画面概要

### 画面名

案件検索

### 想定ルート

`/jobs`

### 画面の目的

フォトグラファーが公募案件を一覧で探し、提案すべき案件を判断できるようにする。

---

## 2. 対象ユーザー

- ログイン済みフォトグラファー
- 公開条件を満たしたユーザー

---

## 3. 主な遷移

| 流入元         | 条件             |
| -------------- | ---------------- |
| ナビゲーション | ログイン済みのみ |

| UI 要素      | 遷移先                                 | 備考   |
| ------------ | -------------------------------------- | ------ |
| 案件カード   | `/jobs/[jobId]`                        | 詳細へ |
| 条件未達導線 | `/mypage/profile`、`/mypage/portfolio` | 補完用 |

---

## 4. レイアウトと UI 要素

- エリア、ジャンル、予算、希望撮影日、並び順
- 結果件数
- 案件カード一覧
- 無限スクロール
- 提案済み状態バッジ

---

## 5. ユーザー操作

- 条件で絞り込む
- 案件詳細へ進む
- 条件未達時はプロフィールまたはポートフォリオ整備へ進む

---

## 6. 状態・バリデーション

| ケース             | 表示                     |
| ------------------ | ------------------------ |
| 未ログイン         | ログインへ誘導           |
| 公開条件未達       | 一覧非表示、補完導線表示 |
| 該当案件なし       | 条件見直しメッセージ     |
| 募集中案件なし     | 全体空状態表示           |
| ネットワークエラー | 再試行導線               |
