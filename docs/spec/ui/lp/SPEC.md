# 画面仕様：LP

## 1. 画面概要

### 画面名

ランディングページ

### ルート

`/lp`

### 画面の目的

未ログインユーザーに対して `PhotoMatch` の価値提案、利用イメージ、安全性、主要 CTA を一貫して提示する。認証導線は現時点ではプレースホルダー表示に留める。

---

## 2. 対象ユーザー

### 主な閲覧者

- 写真撮影を依頼したいユーザー
- 撮影ホストとして登録したいユーザー
- サービスを比較検討中の未ログインユーザー

### 利用シーン

- 広告、SNS、口コミ経由で初回訪問した時
- 会員登録前にサービス内容を確認したい時
- ゲスト利用かホスト利用かを判断したい時

---

## 3. 画面遷移

### 流入

- `/lp` へ直接アクセスする
- ヘッダーロゴ押下で同画面先頭へ戻る

| UI 要素                       | 遷移先                             | 備考                 |

| ヘッダー `安心・安全`         | `#safety`                          | 同一ページ内アンカー |
| ヘッダー `ログイン`           | なし                               | プレースホルダー表示 |
| ヘッダー `無料ではじめる`     | なし                               | プレースホルダー表示 |
| Hero `撮ってほしい方はこちら` | なし                               | プレースホルダー表示 |

- `活躍中のホスト・作品例` の `もっと見る`

- フッターの全リンク

上記はすべて `#` 指定であり、現時点では遷移しない。

## 5. UI 要素詳細

### 5.1 Header

| 要素         | 内容                                                       | 表示ルール        |
| ------------ | ---------------------------------------------------------- | ----------------- |
| ロゴ         | `PhotoMatch` のテキストロゴ                                | 常時表示          |
| アンカーナビ | `サービスとは`、`こんな方に`、`料金の仕組み`、`安心・安全` | `md` 以上のみ表示 |
| ログイン CTA | `Googleでログイン` のプレースホルダーボタン                | `sm` 以上のみ表示 |
| 会員登録 CTA | `無料ではじめる` のプレースホルダーボタン                  | 常時表示          |

### 5.2 Hero

| 要素               | 内容                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| リボン             | `写真のC2Cマッチングサービス`                                        |
| メインコピー       | `プロじゃなくていい。` を主軸にした3行コピー                         |
| リード文           | サービスの価値提案を3行で説明                                        |
| ベネフィットバッジ | `価格はあなたが決める`、`場所もあなたが決める`、`事前チャットで安心` |
| 役割別 CTA         | ゲスト向け、ホスト向けの2ボタン                                      |
| 実績表示           | `登録ホスト`、`マッチング実績`、`平均満足度` の3指標                 |
| スクロールヒント   | 画面下部中央に `SCROLL` を表示                                       |

### 5.3 What Is PhotoMatch

- ゲスト向けカードとホスト向けカードを左右に並べる
- 中央に `× / MATCH` を配置し、両者の接続を視覚化する
- 各カードは画像、役割ラベル、見出し、説明文で構成する

### 5.4 Real Stories

- 2件の利用シナリオカードを表示する
- 各カードは以下で構成する

| 要素       | 内容                                |
| ---------- | ----------------------------------- |
| ケースタグ | `CASE 01 / WEDDING` など            |
| 属性ラベル | 利用者属性                          |
| Voice      | 利用者の悩みを引用形式で表示        |
| メタ情報   | 希望場所、予算                      |
| 解決訴求   | `PhotoMatchでは` から始まる補足説明 |

### 5.5 You Decide Everything

- `価格` と `場所` をテーマにした2カラムカードを表示する
- 各カードは `01` / `02` の番号、大見出し、説明文、具体例で構成する

### 5.6 Use Cases

- 8件の利用シーンカードをグリッド表示する
- 各カードはサムネイル、シーン名、価格目安を表示する
- カード自体はリンク見た目だが遷移先は未設定である

### 5.7 Host Samples

- 4件のホストサンプルカードを表示する
- 各カードは以下で構成する

| 要素       | 内容                         |
| ---------- | ---------------------------- |
| サムネイル | 作品イメージ                 |
| タグ       | `Portrait`、`Family` など    |
| タイトル   | 撮影テーマ                   |
| 評価情報   | 星評価、レビュー件数、エリア |
| ホスト情報 | アバター、表示名、活動属性   |
| 価格情報   | 価格目安、`相談制` バッジ    |

### 5.8 How Pricing Works

- 価格相談制を説明する大型ボックスを表示する
- 3ステップ説明と、一般的なプロ撮影との価格比較カードを表示する
- 比較表示は `一般的なプロ撮影` と `PhotoMatch（相談制）` の2カラム構成とする

### 5.9 Safety & Trust

- 上段に横長カード2件、下段に安心要素カード3件を表示する
- 上段では `事前チャット` と `レビュー・評価` を説明する
- 下段では `本人確認必須`、`安全な決済システム`、`満足保証・返金対応` を表示する

### 5.10 Dual CTA

- 背景画像上にゲスト向け、ホスト向けの2カードを表示する
- 各カードはアイコン、役割名、補足コピー、ベネフィット箇条書き、役割別登録 CTA を持つ

### 5.11 How It Works

- `ゲスト向け` / `ホスト向け` のタブ UI を表示する
- 下部に5ステップの流れを表示する
- 現在の実装ではタブの見た目だけが切り替わり、ステップ内容は両タブで共通である

### 5.12 FAQ

- FAQ をアコーディオン形式で表示する
- 初期表示では先頭項目を開いた状態にする
- 同時に開ける項目は1件のみとする

### 5.13 Final CTA

- サービス総括コピー
- `無料ではじめる` ボタン
- クーポン注記

### 5.14 Footer

- ロゴ
- サービス短文コピー
- 主要リンク群
- コピーライト

## 6. ユーザー操作

### できること

- ヘッダーのアンカーで対象セクションへ移動する
- 認証 CTA の配置と文言を確認する
- `How It Works` のタブを切り替える
- FAQ の開閉を行う

### できないこと

- LP 上でそのまま会員登録やログインを開始する
- LP 上で検索、依頼、提案、チャットを実行する
- ダミーリンクから実画面へ遷移する

---

## 7. 表示ルールと状態

### 表示ルール

- ヘッダーはスクロール後も上部固定する
- ヘッダーナビゲーションは画面幅に応じて表示方法を切り替え、PC とモバイルの双方で主要導線へ到達できるようにする
- 各セクションは背景色、背景画像、グラデーションで視覚的に区切る
- 主要 CTA はゲスト向けとホスト向けで色を分ける

### 状態管理

- FAQ: `openIndex` により開閉状態を保持する
- Steps: `activeTab` を保持するが、表示コンテンツ差分は未実装
- それ以外の本文、件数、サンプルカードは静的データ固定である

### エラー・空状態

- フォーム送信や API 取得がないため、専用のエラー状態は持たない
- 画面内で読み込み中表示は行わない
