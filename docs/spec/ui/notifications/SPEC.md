# 画面仕様：通知一覧

## 1. 画面概要

### 画面名

通知一覧

### 想定ルート

`/notifications`

### 画面の目的

ユーザーが案件関連イベントを一覧で確認し、対象画面へ遷移できるようにする。

---

## 2. 対象ユーザー

- ログイン済みユーザー

---

## 3. 主な遷移

| 流入元         | 条件                                 |
| -------------- | ------------------------------------ |
| ヘッダーバッジ | 未読あり時もなし時も遷移可           |
| プッシュ通知   | アプリ内通知一覧または対象画面直遷移 |

| UI 要素 | 遷移先   | 備考           |
| ------- | -------- | -------------- |
| 通知行  | 対象画面 | 遷移時に既読化 |

---

## 4. レイアウトと UI 要素

- 未読件数表示
- 新着順一覧
- 未読強調表示
- 種別ごとの定型文
- 発生日時

---

## 5. ユーザー操作

- 一覧を確認する
- 通知を既読化する
- 通知から対象画面へ遷移する

---

## 6. 状態・バリデーション

| ケース               | 表示                     |
| -------------------- | ------------------------ |
| 0件                  | 空状態表示               |
| 対象が削除、停止済み | 遷移不可表示             |
| プッシュ未許可       | 画面内告知のみ、機能継続 |
