# 画面仕様：公募作成

## 1. 画面概要

### 画面名

公募作成

### 想定ルート

`/jobs/new`

### 画面の目的

依頼者が撮影条件を公募として投稿し、フォトグラファーから提案を受けられる状態を作る。

---

## 2. 対象ユーザー

- ログイン済み依頼者

---

## 3. 主な遷移

| 流入元     | 条件             |
| ---------- | ---------------- |
| マイページ | 公募投稿導線想定 |

| UI 要素      | 遷移先          | 備考         |
| ------------ | --------------- | ------------ |
| `投稿する`   | `/jobs/[jobId]` | 投稿後詳細へ |
| `キャンセル` | 前画面          | 離脱         |

---

## 4. レイアウトと UI 要素

- 撮影ジャンル
- 希望撮影日
- 撮影エリア
- 予算
- 補足事項
- 募集締切日時
- `投稿する` ボタン

---

## 5. ユーザー操作

- 公募条件を入力して公開する
- 投稿完了後に `募集中` 状態へ遷移する

---

## 6. 状態・バリデーション

| ケース               | 表示     |
| -------------------- | -------- |
| 必須未入力           | 投稿不可 |
| 締切が過去           | 投稿不可 |
| 締切が14日超過       | 投稿不可 |
| 補足事項1000文字超過 | 投稿不可 |
