# 画面仕様：公募詳細

## 1. 画面概要

### 画面名

公募詳細

### 想定ルート

`/jobs/[jobId]`

### 画面の目的

公募内容、現在状態、提案状況を表示し、依頼者には提案比較導線を、フォトグラファーには提案作成導線を提供する。

---

## 2. 対象ユーザー

- 公募を投稿した依頼者
- 公募を閲覧するフォトグラファー

---

## 3. 主な遷移

| 流入元   | 条件                     |
| -------- | ------------------------ |
| 案件検索 | フォトグラファー導線     |
| 通知     | 提案到着、締切、終了通知 |

| UI 要素          | 遷移先                        | 備考                 |
| ---------------- | ----------------------------- | -------------------- |
| `提案する`       | `/jobs/[jobId]/proposals/new` | フォトグラファー向け |
| `提案一覧を見る` | `/jobs/[jobId]/proposals`     | 依頼者向け           |
| `チャットへ進む` | `/chats/[chatId]`             | 採用後               |

---

## 4. レイアウトと UI 要素

- ステータス、締切、提案件数
- 公募条件全文
- 依頼者プロフィール要約
- 依頼者向け管理アクション
- フォトグラファー向け `提案する` CTA

---

## 5. ユーザー操作

- 依頼者は提案一覧へ進み、選択前ならキャンセルできる
- フォトグラファーは提案条件を確認し、提案作成へ進む
- 採用後はチャット導線を表示する

---

## 6. 状態・バリデーション

| ケース             | 表示                        |
| ------------------ | --------------------------- |
| 締切後             | 新規提案不可、比較のみ可    |
| 提案済み           | `提案済みです` を表示       |
| 提案0件で終了      | `キャンセル` 状態と理由表示 |
| 停止、削除済み案件 | 閲覧不可                    |
