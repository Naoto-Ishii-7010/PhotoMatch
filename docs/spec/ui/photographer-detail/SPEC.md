# 画面仕様：フォトグラファー詳細

## 1. 画面概要

### 画面名

フォトグラファー詳細

### 想定ルート

`/photographers/[photographerId]`

### 画面の目的

依頼者がフォトグラファーのプロフィールと公開ポートフォリオを確認し、フォローまたは指名依頼へ進めるようにする。

---

## 2. 対象ユーザー

- 検索結果から遷移した依頼者
- 未ログイン閲覧ユーザー
- 自分の公開状態を確認したいフォトグラファー

---

## 3. 主な遷移

| 流入元            | 条件                                 |
| ----------------- | ------------------------------------ |
| `/search`         | フォトグラファーまたは作品カード押下 |
| `/mypage/follows` | フォロー中カード押下                 |

| UI 要素                  | 遷移先                       | 備考                 |
| ------------------------ | ---------------------------- | -------------------- |
| `フォローする`           | 同画面                       | ログイン必須         |
| `依頼する`               | `/direct-requests/new`       | 対象ID付き想定       |
| ポートフォリオサムネイル | 同画面内拡大またはギャラリー | 個別作品ページはなし |

---

## 4. レイアウトと UI 要素

- アバター、表示名、活動エリア
- 対応ジャンル
- 自己紹介
- フォロワー数
- 公開ポートフォリオ一覧
- `フォローする`、`依頼する` CTA

---

## 5. ユーザー操作

- フォロー / 解除
- 指名依頼フォームへ遷移
- 公開作品を閲覧

---

## 6. 状態・バリデーション

| ケース                     | 表示                             |
| -------------------------- | -------------------------------- |
| 未ログインでフォロー、依頼 | `/auth/login` へ誘導             |
| 自分の詳細を閲覧           | `依頼する` 非表示                |
| 非公開条件未達、停止済み   | 404 相当または閲覧不可表示       |
| 公開作品0件                | 検索公開対象外のため通常流入不可 |
