# 画面仕様：ポートフォリオ詳細

## 1. 画面概要

### 画面名

ポートフォリオ詳細

### 想定ルート

`/portfolios/[portfolioId]`

### 画面の目的

依頼者が1件の公開作品を大きく確認し、その作品を撮影したフォトグラファーのプロフィール確認や指名依頼へ自然に進めるようにする。

---

## 2. 対象ユーザー

- 検索結果の作品カードから遷移した依頼者
- フォトグラファー詳細から個別作品を見たい閲覧ユーザー
- 自分の公開作品表示を確認したいフォトグラファー

---

## 3. 主な遷移

| 流入元                            | 条件                 |
| --------------------------------- | -------------------- |
| `/search`                         | 作品カード押下       |
| `/photographers/[photographerId]` | ポートフォリオ押下   |
| `/mypage/portfolio`               | 公開表示確認導線押下 |

| UI 要素                    | 遷移先                            | 備考                         |
| -------------------------- | --------------------------------- | ---------------------------- |
| `プロフィールを見る`       | `/photographers/[photographerId]` | 撮影者の公開プロフィールへ   |
| `依頼する`                 | `/direct-requests/new`            | ログイン必須、対象ID付き想定 |
| `フォローする`             | 同画面                            | ログイン必須                 |
| 同撮影者の他作品サムネイル | `/portfolios/[portfolioId]`       | 公開作品のみ                 |
| `作品一覧に戻る`           | `/search`                         | 作品タブ復帰想定             |

---

## 4. レイアウトと UI 要素

- メイン作品画像
- タイトル
- ジャンル
- ハッシュタグ
- 説明文
- 公開日時
- 撮影者サマリー
- `プロフィールを見る`、`フォローする`、`依頼する` CTA
- 同撮影者の他の公開作品一覧

---

## 5. ユーザー操作

- 作品画像を閲覧する
- 撮影者プロフィールへ遷移する
- フォロー / 解除を行う
- 指名依頼フォームへ進む
- 同撮影者の他作品へ回遊する

---

## 6. 状態・バリデーション

| ケース                       | 表示                                     |
| ---------------------------- | ---------------------------------------- |
| 未ログインでフォロー、依頼   | `/auth/login` へ誘導                     |
| 自分の作品を閲覧             | `依頼する`、`フォローする` を非表示      |
| 非公開化済み、削除済み、停止 | 404 相当または閲覧不可表示               |
| 画像読込失敗                 | プレースホルダー画像と再読込導線を表示   |
| 他の公開作品がない           | 関連作品セクションを空状態または非表示に |
