# 画面仕様：ポートフォリオ管理

## 1. 画面概要

### 画面名

ポートフォリオ管理

### 想定ルート

`/mypage/portfolio`

### 画面の目的

フォトグラファーが作品を追加、公開切替、削除し、検索掲載条件に必要な公開作品数を管理できるようにする。

---

## 2. 対象ユーザー

- ログイン済みフォトグラファー

---

## 3. 主な遷移

| 流入元           | 条件                   |
| ---------------- | ---------------------- |
| マイページ       | 通常遷移               |
| プロフィール編集 | 公開条件未達の補完導線 |

| UI 要素      | 遷移先                           | 備考                     |
| ------------ | -------------------------------- | ------------------------ |
| `作品を追加` | 同画面内フォームまたは別フォーム | 実装方式未定             |
| 作品カード   | 編集 UI                          | モーダルまたは別画面想定 |
| 公開中作品   | `/portfolios/[portfolioId]`      | 公開表示確認導線         |

---

## 4. レイアウトと UI 要素

- 作品数と公開件数サマリー
- `作品を追加` ボタン
- 新着順グリッド一覧
- 作品ごとのサムネイル、タイトル、ジャンル、公開状態
- 公開切替トグル
- 削除アクション

---

## 5. ユーザー操作

- 画像、タイトル、説明、ジャンル、ハッシュタグ、公開状態を登録する
- 公開 / 非公開を切り替える
- 不要な作品を削除する

---

## 6. 状態・バリデーション

| ケース                         | 表示                    |
| ------------------------------ | ----------------------- |
| 0件                            | 空状態と追加 CTA を表示 |
| 30件到達                       | 新規追加不可            |
| 画像形式不正、15MB超過         | アップロード拒否        |
| タイトル未入力、ジャンル未選択 | 保存不可                |
| ハッシュタグ6件目              | 入力不可                |
