# 画面仕様：プロフィール編集

## 1. 画面概要

### 画面名

プロフィール編集

### 想定ルート

`/mypage/profile`

### 画面の目的

ユーザーが公開プロフィールを編集し、依頼者またはフォトグラファーとして必要な公開条件の達成状況を確認できるようにする。

---

## 2. 対象ユーザー

- ログイン済みユーザー
- 初回登録直後の初期設定ユーザー

---

## 3. 主な遷移

| 流入元     | 条件           |
| ---------- | -------------- |
| 登録完了後 | 初期設定モード |
| マイページ | 通常編集モード |

| UI 要素                | 遷移先              | 備考                     |
| ---------------------- | ------------------- | ------------------------ |
| `保存する`             | 同画面              | 成功トースト表示         |
| `ポートフォリオを追加` | `/mypage/portfolio` | 条件未達時の導線         |
| 初期設定完了           | 次画面未定          | ホームまたは検索導線想定 |

---

## 4. レイアウトと UI 要素

- 表示名
- アバター画像アップロード
- 自己紹介文
- 活動都道府県
- 活動市区町村
- 対応ジャンル複数選択
- 公開条件の達成状況パネル
- `保存する` ボタン

---

## 5. ユーザー操作

- 各プロフィール項目を編集できる
- 保存後に公開条件の達成状況を再計算する
- 初期設定モードでは必須項目入力完了まで離脱警告を出す想定とする

---

## 6. 状態・バリデーション

| ケース                     | 表示                 |
| -------------------------- | -------------------- |
| 表示名未入力               | 保存不可             |
| 自己紹介500文字超過        | 文字数表示と保存不可 |
| 対応ジャンル6件目          | 選択不可             |
| アバター形式不正、10MB超過 | アップロード拒否     |
| 禁止情報を含む             | 保存拒否と修正案内   |
