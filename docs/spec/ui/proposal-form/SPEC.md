# 画面仕様：提案作成

## 1. 画面概要

### 画面名

提案作成

### 想定ルート

`/jobs/[jobId]/proposals/new`

### 画面の目的

フォトグラファーが公募条件を確認した上で、提案金額と提案メッセージを送信できるようにする。

---

## 2. 対象ユーザー

- ログイン済みフォトグラファー
- 公開条件達成済みユーザー

---

## 3. 主な遷移

| 流入元   | 条件       |
| -------- | ---------- |
| 案件検索 | `提案する` |
| 公募詳細 | `提案する` |

| UI 要素      | 遷移先          | 備考               |
| ------------ | --------------- | ------------------ |
| `送信する`   | `/jobs/[jobId]` | 提案済み状態に戻る |
| `キャンセル` | `/jobs/[jobId]` | 離脱               |

---

## 4. レイアウトと UI 要素

- 公募サマリー
- 提案金額
- 提案メッセージ
- 依頼条件の再掲
- `送信する` ボタン

---

## 5. ユーザー操作

- 金額とメッセージを入力して送信する
- 締切前のみ送信できる
- 提案済みの場合は新規送信できない

---

## 6. 状態・バリデーション

| ケース                            | 表示                       |
| --------------------------------- | -------------------------- |
| 提案済み                          | 送信不可、既存提案状態表示 |
| 締切後                            | 送信不可                   |
| 金額未入力、0円以下               | 送信不可                   |
| メッセージ1文字未満、1000文字超過 | 送信不可                   |
