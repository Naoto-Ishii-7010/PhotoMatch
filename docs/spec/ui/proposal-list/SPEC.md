# 画面仕様：提案一覧・比較

## 1. 画面概要

### 画面名

提案一覧・比較

### 想定ルート

`/jobs/[jobId]/proposals`

### 画面の目的

依頼者が公募に届いた提案を比較し、1件を採用できるようにする。

---

## 2. 対象ユーザー

- 公募を投稿した依頼者

---

## 3. 主な遷移

| 流入元   | 条件                 |
| -------- | -------------------- |
| 公募詳細 | `提案一覧を見る`     |
| 通知     | `公募へ提案が届いた` |

| UI 要素    | 遷移先            | 備考         |
| ---------- | ----------------- | ------------ |
| 提案カード | 同画面            | 詳細展開     |
| `採用する` | 同画面            | 確認後確定   |
| 採用完了後 | `/chats/[chatId]` | 調整開始導線 |

---

## 4. レイアウトと UI 要素

- 公募サマリー
- 提案件数
- 比較カード一覧
- 各カードに提案金額、提案文、プロフィール要約、代表作品、採用 CTA

---

## 5. ユーザー操作

- 各提案を比較する
- 1件を採用する
- 採用前なら公募詳細へ戻ってキャンセル判断する

---

## 6. 状態・バリデーション

| ケース           | 表示                         |
| ---------------- | ---------------------------- |
| 提案0件          | 空状態と公募詳細への戻り導線 |
| 締切後72時間超過 | `キャンセル` 扱い            |
| 既に採用済み     | 採用ボタン非表示、結果表示   |
