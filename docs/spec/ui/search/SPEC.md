# 画面仕様：フォトグラファー検索

## 1. 画面概要

### 画面名

フォトグラファー検索

### 想定ルート

`/search`

### 画面の目的

依頼者がフォトグラファー検索と作品検索を切り替えながら候補を探し、詳細ページへ遷移できるようにする。

---

## 2. 対象ユーザー

- 未ログイン閲覧ユーザー
- 撮影を依頼したいログイン済みユーザー

---

## 3. 主な遷移

| 流入元   | 条件                  |
| -------- | --------------------- |
| LP       | 将来導線想定          |
| 直接流入 | SEO、ブックマーク想定 |

| UI 要素                    | 遷移先                            | 備考               |
| -------------------------- | --------------------------------- | ------------------ |
| フォトグラファーカード     | `/photographers/[photographerId]` | 詳細へ             |
| 作品カード                 | `/portfolios/[portfolioId]`       | 作品個別詳細へ     |
| `依頼する`、`フォローする` | ログイン時のみ有効                | 詳細ページ上で実行 |

---

## 4. レイアウトと UI 要素

- タブ
  `フォトグラファー`、`作品`
- 検索条件パネル
- 並び順セレクト
- 結果件数表示
- カード一覧
- 無限スクロール読み込み

---

## 5. ユーザー操作

- タブを切り替える
- 条件を変更して結果を更新する
- カードから詳細ページへ進む
- 条件なし状態へリセットする

---

## 6. 状態・バリデーション

| ケース                 | 表示                               |
| ---------------------- | ---------------------------------- |
| 該当なし               | 条件見直しメッセージとリセット導線 |
| ネットワークエラー     | 再試行ボタン                       |
| 追加読み込み中         | ページ末尾ローディング表示         |
| 非公開化済み詳細へ遷移 | 閲覧不可表示後に一覧復帰           |
